   на потоке писателя `t_sink_owner` ложно — проверка обрывается на чтении TLS; на пути `=0` без стенда `SinkWrite` не
   зовётся. Без неё сбой «внутри записи под `g_sink_mutex`» в тесте не получить (п. 616(б)(3)).
4. **Положительный контроль RC4 — не «висит»** (буква п. 616(б)(3) «на коде до правки висит» — **не выполнена**, §4).
