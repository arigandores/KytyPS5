## 2. Отнесение кадров ≥ 100 мс на удержании (RC8)

### 2.1 Популяция и тождества

Популяция — та же, что `rep_f32a.py` (3) на сводном входе: логи линии курса с FS2 без валидации (`[Vulkan][W]` < 100), правило кадров F0
(`agg_f0.py frames()`, загружен без изменений): первый кадр сцены — первая `FrameTrace` с `draws` ≥ 100 после строки уровня, окно — 599 кадров,
дальше удержание. `frames_f32d.py` перечисляет все кадры удержания ≥ 100 мс тем же правилом (у `frames()` списки примеров обрезаны) и сверяет
с ним каждый вход (I1: K3 и K2 удержания на вход = `frames()`), затем один проход по каждому логу собирает метки интервала кадра (строки после
предыдущей главной `FrameTrace: n=` до своей). Самопроверки (`sum_f32d.out.txt`, `ALL OK`): I1 — 291 вход; I2 — строк таблицы 267 K3 + 13 K2 =
итог `rep` (3); I3 — по каждому уровню = строке `rep` (3); I4 — сумма по классам = 280; I5 — часть логов F32a + часть 36 логов = 280, у части
F32a K3 = 239 (= `rep_f32a.out.txt` F32a).
