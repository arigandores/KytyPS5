## 4. Строки ридера (`f9g_read.py`, по тегу; вердикт «ИСПРАВЛЕНО» ридер не печатает)

- **Строка `FixB42:`** формы п. 353(г)(3): `FixB42: mode=<0|1> hit=<n> applied=<n> drawn=<n> rearm=<n> hit_all=<n> last_frame=<n> extent=<w>x<h>
  cmask=0x<addr> clear=<w0>/<w1>`; `hit`, `applied`, `drawn`, `rearm` — счётчики экстента строки, `hit_all` — сумма; взведённость записи `CMask` —
  по битам слоёв вида (п. 357(г)(1)); рваная строка считается отдельно. **Рост** счётчика — значение минус значение на предыдущей строке того же
  экстента (до первой — 0).
- **Форма:** все строки `mode` = ожидаемому (1 у V/W/SG/HB, 0 у C0), иначе `FORM ERROR`; `GamePatch:` — 0.
- **present позиции лога** = `n` следующей строки `FrameTrace` + сдвиг (медиана «present − n» по строкам `InputScript: press|release … (present P)`;
  кадр видео v = present − 1, `.idx`). Фазы (форма F9d): подход present < 3841; **«в воде с вращением»** [3841, 5851) (v [3840, 5850));
  шаги [5851, 5951); **«неподвижная камера сбоку»** ≥ 5951 (v ≥ 5950) до последнего present прогона.
- **(г)(1) член целостности V1/V2** (п. 353(д)(1)): есть строка `extent=960x540` с ростом `applied`, чей present не позже последнего present фазы
  «неподвижная камера сбоку» (= последний present прогона), **и** между любыми двумя строками `extent=960x540` (и от 0 до первой) рост `hit` не больше
  роста `applied`. Печатаются первая такая строка (номер, present, фаза) и число таких строк в неподвижной фазе — справка.
- **(г)(2) C0** (п. 351(г)(2), п. 353(д)(2)): строка `mode=0`, `extent=960x540`, `hit` ≥ 1, `applied=0`; плитки — по листу (§5).
- **`hit = 0` при `=1`** (п. 349(г)(6), по букве): ни одной строки `FixB42:` с `hit_all` ≥ 1 — нечитаемо, один повтор тега. Вариант исполнителя рядом
  (справка): нет строки `extent=960x540` с `hit` ≥ 1.
- **`drawn`, `rearm`** по экстентам — справка (п. 353(д)(3)); `drawn` > 0 у `extent=960x540` в V1/V2 — строка «не исправлено, читать так: T6
  получил draw» и вопрос лиду до чтения листов V1/V2 (остальные теги идут).
- **`clear`** строк `960x540` и `480x270`, `cmask` строк `960x540` — справка (п. 351(г)(3)).
- **Вход** — первая строка `GuestOut: Level has started: <уровень формы>`; смена сцены — любая следующая такая строка; первый кадр сцены — первая
  строка `FrameTrace` после входа с `draws` ≥ 100. **Кадры ≥ 1 с** — строки `FrameTrace` с `dt_us` ≥ 1 000 000 после первого кадра сцены (до смены
  сцены) — член; по всему логу — справка. **Удержание** — сумма `dt_us` после первого кадра сцены (SG/HB: ≥ 300 с).
- **Маркеры смерти** — `Unhandled exception:`, `--- Fatal Error ---`, `--- Error ---`, `GpuHangAbort:`, `ErrorDeviceLost` в логе и stdout эмулятора.
- **W:** `[Vulkan][E]` — 0; валидация активна — ≥ 1 строки `[Vulkan][W][2]`/`[Vulkan][E][2]`; строки «last time reporting it» — справка;
  `DualSrcBlend: supported=1 enabled=1` до первой строки с `GuestOut`; `hit_all` ≥ 1.
- Справка: `AsyncPipelines: skipped draw` (форма Б5), события окна, записи `.idx`, строки `FrameTrace`.
- **Видео:** кадров и записей `.idx` — строка `s51_vidglitch.py <rec> 4 6` («frames …, index entries …»); член — ≥ 3 000 кадров;
  одно-кадровые глитчи `s51_vidglitch.py 4` — 0 (для Б42 необходимо, не достаточно — п. 349(а)).
