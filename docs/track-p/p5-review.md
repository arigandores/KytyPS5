**RC2 — целостность пар B: одна укороченная пара даёт ложный `SPEED_OK`.** Скорость B = Σ D / Σ стены пар B (`scp4.py:286–294`), где
D — постоянная имени из A; разброс проверяется только в A (`:272`). Пара B, закрытая раньше естественного конца (P3 §3 / п. 236(г):
пороги длины узла `0x4f4fe9`… дают клипу длину 0 при 1/30; `Finished` после `Stop`/смешивания; второй экземпляр того же имени,
поздний `Play` которого укорачивает пару — счётчик `restarts` общий и не решает), прибавляет полное D при малой стене. *Сценарий*
(атака A1, `out/rt_p5.out.txt`): 3 имени, по 4 пары B на 60 кадрах, истинная скорость 0,88 → `SPEED_LOW 0,8800`; добавить к каждому
имени одну пару B из 6 кадров (медиана отношения не меняется) → **`SPEED_OK 1,1355`**. *Изменить:* в скорость B — только пары B с
собственным отношением ∈ [0,45; 0,55], или разброс B ≤ 2 % вокруг медианы B (зеркало правила A); исключённые пары и счётчики
`restarts`/`orphans` — по имени и по плечу. Решение формы — лида.

**RC3 — ширина окна [0,45; 0,55] даёт смещение скорости B до ±11 %.** Измеренная скорость = 1 / (60 · r · dt_B), истинная (шаг 1/30) =
1 / (30 · dt_B); отношение 1 / (2r) = 1,111 при r = 0,45 и 0,909 при r = 0,55. *Сценарий* (A2): имена с r = 0,45 (длительность в
игре не чисто шаговая), истинная скорость 0,86 → **`SPEED_OK 0,9556`**. *Изменить:* печатать рядом «шаговое прочтение» Σ (кадры B / 30) /
Σ стены B; `SPEED_OK` — только если оба ≥ 0,95 (вариант исполнителя) либо лид сужает окно для скорости (не для признака правки).

**RC4 — `SPEED_OK` по выборке пар, а не по удержанию.** П. 226(г)(1): «≥ 0,95 на ≥ 300 с удержанной сцены»; скорер требует ≥ 300 с

пары трёх имён часов лежат в спокойных отрезках (герой стоит между блоками ввода, кадры 33 мс), прыжки и ходьба идут на 3 вблэнках
→ скорость по парам 0,97, 33 333 / mean `dt_us` удержания B = 0,80 → `SPEED_OK`, сцена на 300 с медленнее порога. *Изменить:* вопрос лиду —
`SPEED_OK` требует и строку представительности B (расхождение ≤ 3 %), либо минимум двух; печатать долю стены удержания под парами.

## 5. Чек-лист

Положительный контроль: калибровка счёта пар на `s10` — не тавтология (реальные пары, 755 / 180); контроль (е)(3) — тавтология
(п. 240(б), согласен). Нулевой контроль: офлайн A = B даёт все отношения 1 и `PATCH_INACTIVE` по L1 — верно; в прогоне нуля нет (плечо
A не повторяется). Типы: `dt_us` — мкс, D — с, скорость = Σ D · 10⁶ / Σ мкс — без смешения. Тождества: стена удержания = Σ `dt_us`
строк удержания; пары — подмножество, не разбиение (RC4). Инструмент меняет прогон: `27e46c` включает лог игры в обоих плечах —
проекция `v142` (без лога) не представляет A (сказано печатью §5) и усиливает RC1. Шейдеры не трогаются. Недоказанное печать
называет (§7), но не называет RC1.
