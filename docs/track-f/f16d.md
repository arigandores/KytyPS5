## 3. Ф6 — слоты цвета команды draw хоста (п. 433(в)–(г), F17a §4)

- Ручка `KYTY_DIAG_F6` (умолчание 0), тот же модуль `diagF5.h/.cpp`, тот же коммит и бинарь.

Читает только `state.color_info[i].target_slot` хостовых вложений, регистры гостя `CB_COLORn_*` из `buffer.GetRegisters()` и выходы `ShaderInfo::outputs` вида `Mrt` программы PS (индекс гостя; у варианта dual-source индекс гостя тот же).
- Класс слота гостя (8 слотов на draw) — по (маска ≠ 0, база ≠ 0, сырое `FORMAT` `CB_COLORn_INFO` ≠ 0): `s_bound`, `s_addr0_fmt`, `s_addr0_nofmt`, `s_mask0_addr`, `s_empty`; `h_bound` — слоты с хостовым вложением; `bound_missing` / `bound_extra` — расхождения хоста и класса `s_bound`; экспорты MRT PS: `w_total` = `w_bound` + `w_mask0` + `w_addr0_fmt` + `w_addr0_nofmt` + `w_ge8`; `ps_draws` — draw с активной программой PS.
- Тождества: `s_bound + s_addr0_fmt + s_addr0_nofmt + s_mask0_addr + s_empty = 8 · draws`; `h_bound = s_bound − bound_missing + bound_extra`; `w_total = w_bound + w_mask0 + w_addr0_fmt + w_addr0_nofmt + w_ge8`; `draws_idx + draws_auto + draws_ind + draws_mesh = draws`; `ps_draws ≤ draws`. Правило чтения — п. 433(в)(i)–(iv) (`w_addr0_fmt` = 0 и инварианты 0 на 4 тегах — `НЕ ДЕФЕКТ`) — у F16g, не здесь.

## 7. Вопросы лиду (поправка констант — не правка кода; по умолчанию исполнителя — справка)

- **В-F16d-1 (`cmask_fce_layout`).** Разбиение семьи `cmask_fce` по порядку тестов `FixB42Probe` даёт ребёнка, которого нет ни в B, ни в справке п. 427(б): FCE на CMASK-цели без метаданных с `levels ≠ 1`, объёмная, или обе стороны кратны 1024 без метаданных (последнее при `levels == 1` и не объёме недостижимо: такая цель получает метаданные CMASK в `colorRenderTarget.cpp`). Класс тот же, что `cmask_fce_msaa` («Б42 и условие `:441` не берут вовсе»), но в B лид его не назвал. Счётчик поставлен; по умолчанию — справка, вне B; правило чтения F16g решает лид.
- **В-F16d-2 (`cmask_fce_noimage`, `meta_dma_noclear`).** Дети нужны для точного разбиения, но вне B: `noimage` по коду недостижим (полное разрешение с базой ≠ 0 всегда даёт образ или `EXIT`); `meta_dma_noclear` — DMA-fill известного адреса значением, которое не код очистки (по RC3 — законная инициализация). По умолчанию — справка.
- **В-F16d-3 (`fmask_read`).** Место вне набора подписи нашлось, но население частичное: перестановка программы, найденная поиском по специализации (`pipelineCache.cpp`), в специализации которой есть образ FMASK; попадания memo и первая трансляция перестановки сюда не доходят.
