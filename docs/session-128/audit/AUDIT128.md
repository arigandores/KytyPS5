**Закрытию:** явно запарковать OLD как долг K14 (§5 п. 1). Если скорер переиспользуется — отнести 0 пар к `DEBT` с
фикстурой.

## 4. Что НЕ доказано

1. **Что Δ `pd128` равен выигрышу какого-либо механизма.** Δ — чувствительность `dt` к удвоению времени вызовов
   (калибровка). Потолок их снятия ≈ Δ — только при линейности [I]. Δ / доза = 0,774: снятие 1,31 мс вызовов сдвинуло бы
   среднее на ≈ 1,0 мс, если отклик симметричен. Это не проверено.
   * Спин не воспроизводит побочных эффектов вызова ядра (сброс TLB и т. п.) [U] — в эту сторону Δ занижен.
   * Доза держит замки региона/`apply`, поэтому в Δ входит ожидание других потоков [U] — в эту сторону Δ может быть и
     завышен как оценка «времени одного GuestGpu».
   * Фолты гостя и повторные загрузки в Δ не входят вовсе.
2. **Что механизм, снимающий вооружение с GuestGpu, окупится.**
   * `protceil=1` (пропуск вооружения) повесил GPU за 4 кадра в 2 из 2 дымов. Вооружение несёт живые данные CPU → GPU, и
     механизм обязан перенести обнаружение записи, а не выбросить его (п. 93(б)).
   * Прежние переносы вооружения (`armdefer` с. 60: +4,5…+7,8 % в пустыне; `protbatch2` с. 58: в шуме) не окупились.
   * `K14_OPEN` даёт право на прототип с ABBA, а не прогноз его Δ.
3. **Режим OLD.** 0 пар в `pd128`. Дым `s4s128` в OLD (+995 ± 269) — ряд, не вердикт.
4. **Другие сцены.** Только опора Sky Garden.
5. **База против установленной сборки.**
   * База 31 700,6 мкс (52,58 %) — на измерительной `45d36512` (весь код `protceil` при 0), не на установленной `9235a7ac`.
   * С 50,36 % (`k3p127`, `98d98eee`, `rtskip=0`) не сравнивается. Межпрогонная разность баз (−1 395 мкс) больше Δ
     отгрузки (−386) в 3,6 раза — это НЕ измерение, ни как скорость отгрузки, ни как цена кода.
   * Время самой установленной `9235a7ac` не мерено ни одним прогоном. Цена ручек при 0 против `d3a981a2` — долг с. 127.
6. **Отгрузка `rtskip=1`** доказана как «живёт в установленной сборке»: строка, Σ`rts_skip`, видео 120 с без глитчей, лист
   кадров. Выигрыш — только против плеча 0 `98d98eee` (с. 127). OLD, другие сцены, значения на траектории режима 1,
   попиксельная картинка — не доказаны (с. 127 §4).
7. **Какая операция GPU виснет при `protceil=1`** — [U], не мерено (решение п. 93(б)).
8. **Корректность кода `protceil` при 1/2 тестами** — нет ни одного теста на значения ≠ 0 (п. 90(а)); `page_manager_tests`
   не линкуется с `c7516a8a` (старое).
9. **Скорость игры.** Среднее `dt` ≈ 31,7 мс ≈ 2 вблэнка. Δ дозы прибавляет время и не прогноз FPS. 60 FPS не обещаются.
