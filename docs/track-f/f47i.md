## 4. Определения (до данных)

- **d** = последний показ `.idx` − последний n `FrameTrace` (F47a §1.3, F47e §6); **показ записи видео** n = показ − d.
- **Детектор F47a §1.3** (правило `batch_f47a.py`, код ридера — порт `f47d_read.py`): записи видео [n₀ + d + 599; n₀ + d + 949] → ffmpeg 480×270

  с Wt ≥ 1 000; показы серии — n записей серии.
- **Строка H** — строка `F47dt: kind=draw` с `ps=45942b26d9ffbe8e`; её показ — поле `q`.
