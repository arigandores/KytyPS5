## 1. Решено измерениями — не переоткрывать

- **B3 (`progmemo`) включён**: −1,3 / −2,9 / −2,9 % CPU на draw в полосе 4700–5100, 75 % стадий и
  76 % ключей пайплайна по memo. Свидетель — все входы `PrepareProgram` кроме значений user SGPR
  (§2 отчёта); любая новая зависимость `PrepareProgram`/`ShaderGetStaticInputInfo*` от регистров
  или гостевой памяти обязана попасть в `ProgMemoWitness` или в запись таблиц. Самопроверка
  `progmemocheck`.
- **`dawalk` закрыт**: с `dawalklead=1/2` регрессии нет, выигрыша тоже (−0,3…−1,4 %). Не
  возвращаться.
- **Защита страниц после загрузки закрыта**: потолок 1,6 мс на кадр (5 %), реализация `armdefer`
  на пустыне +4,5…+7,8 % — страницы, записанные один раз, загружаются дважды. Гейт 0. Если
  возвращаться — только с осадкой сравнением на воркере или только для горячих страниц (§4 отчёта),
  потолок ≈1 мс.
- B9, M2-числа, `rtfast`, B5/B7/B1d — см. `docs/next-session-60.md` §1. Подпись кэша трансляции
  в сессии 60 не менялась.
- Необъяснённый прогон `sig1` сессии 59 (гостевой assert «too many objects/batches») в сессии 60
  не повторился (9 прогонов пустыни).

## 2. Работы сессии (по отношению выгода/риск)

1. **Профиль потока GuestGpu после `progmemo`** — одна фаза с семплером в первом же свипе
   (`samples_phase.py`); без него следующие пункты — догадки по профилю сессии 57.
2. **Загрузки буферов пакетом.** 72 загрузки на кадр, 23 МБ; каждая — `EndRendering` +
   два барьера + `copyBuffer` (`RecordBufferCopies`). Сначала счётчик потолка: сколько загрузок
   кадра идут подряд без draw между ними и сколько разрывов render pass они делают
   (`FrameTrace-rp`, причина `BufferUpload`); затем одна пара барьеров и один `copyBuffer` со
   списком регионов на серию.
3. **Накладные M1 на критическом потоке** (`VerifyWitness` 4,3 %, `AheadTake` 2,5 %,
   `QueueAheadSource` 1,8 %) — дешевле проверять: свидетель по эпохам регионов вместо байтов?
   Сначала счётчик: доля свидетелей, у которых сдвиг обнаруживается первым же словом.
4. **M2** — только с числами §6 сессии 59 перед глазами и после 1–3.
