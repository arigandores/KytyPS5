## 5. Вопросы лиду (по каждому — вариант исполнителя; до ответа скорер считает по варианту)

1. «≥ 3 имени часов» п. 312(д)(1) читается как ≥ 3 **имени скорости** (имена часов с ≤ 20 % нецелых пар) — как в `03` (`len(spd) < MIN_NAMES`); имена скорости ⊆ имён часов, прочтение строже буквы. Вариант исполнителя — прочтение `03`.
2. `PATCH_INACTIVE` (п. 240(а)) в G1′ недостижим: без окна «нет имени часов» значит «нет имени с разбросом ≤ 0,02», а признак 240(а) требует ≥ 3 таких имён. Неактивная правка видна как `SPEED_LOW` (имена со своим 1/60 идут со скоростью FPS/60). Строка 240(а) печатается («sign of item 240 (a) … inactive»). Вариант исполнителя — так.
