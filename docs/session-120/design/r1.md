## 0. What the census answers, and the population it works on

**Question.** The texture memo of `ResolveTextureWith` is direct-mapped, 4 096 slots (`renderMemo.h:114`,
`descriptors.cpp:1469-1471`, `memo_hash % 4096`). On a miss the whole resolution runs (`descriptors.cpp:1538-1711`:
tile layout, validation, `TextureCache::FindImage`, memo store) and the store resets the slot's texfast view
(`:1705`), so `RebindImages` re-records a view (`:2605-2620`). How much of that would a table of a different shape
remove — a **4-way LRU of the same 4 096 entries**, an **8-way LRU of the same 4 096 entries**, a **direct table of
16 384 slots** — measured, not inferred, and with the proof that such a table's hit would have returned exactly what
the real resolution returned?

**Population** (my re-parse of `C:/kyty/s118/log_spk118.txt`, arm 1 = the s119 reference arm, frames 10–88 of every
block, `draws > 3000`, 2 994 frames, means a frame; scratchpad script, not a seal):

| counter | mean | meaning |
|---|---:|---|
| `b_texn` | 50 370.3 | all `ResolveTextureWith` calls (`Scope` count, `:1371`) |
| `tnull_hit` / `tnull_miss` | 1 481.8 / 0.0 | null T#: returns at `:1425`/`:1433`/`:1438`, before the memo — **not** in this census |
| `tex_hits` | 47 108.8 | real memo hits (`:1515`) |
| `texmemo_collide` / `texmemo_empty` | 1 771.9 / 0.2 | key misses (`:1477-1479`) |
| `texmemo_stale` | 7.4 | key matched, image failed liveness (`:1531`) |
| `texfast_ok` / `texfast_no` / `texfast_rec` | 45 394.3 / 4 864.8 / 1 530.8 | `RebindImages` texfast outcomes (`:2648-2652`) |

So the census sees ≈ 48 888 memo lookups a frame, of which ≈ 1 772 are key misses — the only lookups a bigger table
can turn into hits (a stale miss cannot, §2.1.4).

**Prediction (not a seal, for orientation only):** with t_miss ≈ 450–500 ns and t_hit ≈ 20–35 ns on the intervals
defined in §2.2, even if every key miss were fixable the ceiling is ≈ 1 772 × ~450 ns ≈ 0.80 ms, plus ≤ 0.06 ms of
texfast re-records — the s119 reading-level 0.70–0.90 ms [I]. The census turns that into [M].

#### 2.1.1 Data

```cpp
+// Session 120, knob "r1cen" (MEASUREMENT ONLY, C:/kyty/s120/design/r1.md).  1: the real memo's key-miss path and a
+// 1/8 random sample of its hit path are timed (branch -> emit), RebindImages times its texfast re-record branch and a
+// 1/16 sample of its fast branch.  2: plus a TAG-ONLY SHADOW of three other memo shapes - 4-way and 8-way LRU of the
+// same 4 096 entries, direct 16 384 - that sees every lookup of the real memo, decides "would have hit" with the real
+// hit's own proof (64-bit resource key, 32-byte T#, five-field liveness) and checks that claim against what the real
+// miss path computes (r1_*_bad).  It reads images through SlotVector::try_get only; it never writes the memo, the
+// texture cache or an image, and nothing it computes feeds a decision.
+namespace R1 {
+constexpr uint32_t W4Sets   = 1024;  // x 4 ways = 4 096 entries
+constexpr uint32_t W8Sets   = 512;   // x 8 ways = 4 096 entries
+constexpr uint32_t D16Slots = 16384; // direct
+// One cache line; read only on a real key miss or written on a fill, never on a real hit (except 1/64 sampled d16).
+struct Proof {
+	uint64_t                resource_key = 0;   // the real memo's resource_key (hash of the ImageResource prefix)
+	std::array<uint32_t, 8> dwords {};          // the full T#
+	ImageId                 image_id;           // {index, generation} the fill resolved to
+	uint64_t                desc_digest = 0;    // R1DescDigest of the desc the fill resolved to
+	uint32_t                gen = 0;            // d16 only: census generation of the fill (other gen = empty)
+	uint32_t                spare = 0;
+};
+static_assert(sizeof(Proof) == 64);
+// Tag = high 32 bits of memo_hash; the set index uses the low bits. use == 0 means an empty way.
+struct alignas(32) Set4 { std::array<uint32_t, 4> tag {}; std::array<uint32_t, 4> use {}; };
+struct alignas(64) Set8 { std::array<uint32_t, 8> tag {}; std::array<uint32_t, 8> use {}; };
+struct Cand {                 // this lookup's exact-proof candidate in one table
+	bool         found = false, live = false;
+	uint32_t     slot  = 0;     // index into the table's Proof array
+	ImageId      id;
+	uint64_t     digest = 0;
+	GuestRange   data {};       // the candidate image's info.data / info.extent as the liveness test saw them
+	vk::Extent3D extent {};
+};
+struct Census {
+	const RenderExecutorMemo* memo = nullptr;
+	uint32_t gen = 0, block = 0, clock = 0;
+	int      frame = 0;
+	bool     post = false;      // this key miss evaluates liveness AFTER the real miss path (warming control, 5.3)
+	bool     self = false;      // this lookup's own census work is timed (1/64)
+	uint64_t self_ns = 0;
+	ImageId  real_before;       // stale lookups: the real slot's image id before :1533 invalidated it
+	std::array<Cand, 3> cand {};                                       // [0] w4, [1] w8, [2] d16
+	std::array<uint64_t, RenderExecutorMemo::TextureSlots / 64> observed {}; // real slot content filled while watched
+	std::array<uint8_t, RenderExecutorMemo::TextureSlots> mark {};    // bit T: the slot's last fill was a would-hit in T
+	std::vector<Set4>  w4  = std::vector<Set4>(W4Sets);
+	std::vector<Proof> w4p = std::vector<Proof>(W4Sets * 4);
+	std::vector<Set8>  w8  = std::vector<Set8>(W8Sets);
+	std::vector<Proof> w8p = std::vector<Proof>(W8Sets * 8);
+	std::vector<Proof> d16 = std::vector<Proof>(D16Slots);
+};
+} // namespace R1
+// GuestGpu is the only thread that resolves textures; a census on any other thread would see part of the traffic
+// and trip r1_incl.  Allocated on the first armed lookup (about 1.7 MB), never at r1cen 0.
+static thread_local std::unique_ptr<R1::Census> t_r1;
+static thread_local uint32_t                    t_r1_rng = 0x2545F491u;
+static uint32_t R1Next() {  // xorshift32: the hit, fast-branch, mode and self samples (not periodic: no slot aliasing)
+	auto x = t_r1_rng; x ^= x << 13u; x ^= x >> 17u; x ^= x << 5u; return t_r1_rng = x;
+}
```

```cpp
+static uint32_t R1Tag(uint64_t h) { return static_cast<uint32_t>(h >> 32u); }
+static bool R1Same(const R1::Proof& p, uint64_t rk, const uint32_t* dwords) {  // THE REAL HIT'S KEY TEST (:1474-1475)
+	return p.resource_key == rk && std::memcmp(p.dwords.data(), dwords, sizeof(p.dwords)) == 0;

+// Every field of ImageDesc a consumer reads, packed member-wise into zeroed words (never memcmp/hash of the struct:
+// ImageDesc has padding - see the bindpackcheck comment at :1397-1401), then XXH3.
+static uint64_t R1DescDigest(const TextureCache::ImageDesc& d) {
+	std::array<uint64_t, 80> w {}; size_t n = 0; const auto& i = d.info; const auto& v = d.view_info;
+	w[n++] = i.data.address; w[n++] = i.data.size; w[n++] = i.stencil.address; w[n++] = i.stencil.size;
+	w[n++] = i.metadata.range.address; w[n++] = i.metadata.range.size;
+	w[n++] = uint64_t(i.metadata.kind) | uint64_t(i.metadata.compression) << 8u | uint64_t(i.metadata.stencil_compressed) << 16u
+	       | uint64_t(i.metadata.dcc_clear_register_valid) << 17u | uint64_t(i.metadata.dcc_alpha_msb) << 18u;
+	w[n++] = i.metadata.control | uint64_t(i.metadata.dcc_clear_word) << 32u;
+	w[n++] = i.metadata.cmask_clear_words[0] | uint64_t(i.metadata.cmask_clear_words[1]) << 32u;
+	w[n++] = i.htile_clear_mask | uint64_t(uint32_t(i.pixel_format)) << 32u;
+	w[n++] = uint32_t(i.guest_format) | uint64_t(uint32_t(i.type)) << 32u;
+	w[n++] = i.extent.width | uint64_t(i.extent.height) << 32u;  w[n++] = i.extent.depth | uint64_t(i.resources.levels) << 32u;
+	w[n++] = i.resources.layers | uint64_t(i.pitch) << 32u;      w[n++] = i.bytes_per_block | uint64_t(i.samples) << 32u;
+	w[n++] = uint32_t(i.tile_mode) | uint64_t(i.bgra16) << 32u;
+	for (uint32_t l = 0; l < std::min<uint32_t>(i.resources.levels, 16u); l++) {
+		w[n++] = i.mip_layout[l].offset; w[n++] = i.mip_layout[l].size;
+		w[n++] = i.mip_layout[l].pitch | uint64_t(i.mip_layout[l].height) << 32u;
+	}
+	w[n++] = uint32_t(v.format) | uint64_t(uint32_t(v.type)) << 32u;
+	w[n++] = uint32_t(VkImageAspectFlags(v.aspect)) | uint64_t(v.base_level) << 32u;
+	w[n++] = v.level_count | uint64_t(v.base_layer) << 32u;   w[n++] = v.layer_count | uint64_t(v.min_lod) << 32u;
+	w[n++] = uint32_t(v.mapping.r) | uint64_t(uint32_t(v.mapping.g)) << 32u;
+	w[n++] = uint32_t(v.mapping.b) | uint64_t(uint32_t(v.mapping.a)) << 32u;
+	w[n++] = uint32_t(VkImageUsageFlags(v.usage)) | uint64_t(uint32_t(d.type)) << 32u;
+	w[n++] = d.source_first_level; w[n++] = d.source_size;
+	return XXH3_64bits(w.data(), n * sizeof(uint64_t));   // n <= 16 + 48 + 9 = 73
+}
+// THE REAL HIT'S LIVENESS TEST (:1482-1485), minus the data/extent comparison, which needs the desc: R1Miss finishes it.
+static void R1Live(R1::Cand& c, const Common::SlotVector<Image>& images) {
+	const Image* img = images.try_get(c.id);
+	c.live = img != nullptr && img->registered && !img->binding.needs_rebind && !img->depth_id;
+	if (img != nullptr) { c.data = img->info.data; c.extent = img->info.extent; }
+}
+template <typename Set> static int R1FindTag(const Set& s, uint32_t tag) {        // real hits: tag only (5.1)
+	for (int w = 0; w < int(s.tag.size()); w++) if (s.use[w] != 0 && s.tag[w] == tag) return w;
+	return -1;
+}
+template <typename Set> static int R1FindExact(const Set& s, const R1::Proof* p, uint32_t tag, uint64_t rk,
+                                               const uint32_t* dwords) {         // key misses: full proof
+	for (int w = 0; w < int(s.tag.size()); w++) {
+		if (s.use[w] == 0 || s.tag[w] != tag) continue;
+		if (R1Same(p[w], rk, dwords)) return w;
+		Common::FrameStats::Add(Common::FrameStats::Counter::R1TagAlias, 1);
+	}
+	return -1;
+}
+template <typename Set> static int R1Victim(const Set& s) {  // an empty way, else the least recently used
+	int best = 0;
+	for (int w = 0; w < int(s.use.size()); w++) { if (s.use[w] == 0) return w; if (s.use[w] < s.use[best]) best = w; }
+	return best;
+}
+static void R1Put(R1::Proof& p, uint64_t rk, const uint32_t* dwords, ImageId id, uint64_t digest, uint32_t gen) {
+	p.resource_key = rk; std::memcpy(p.dwords.data(), dwords, sizeof(p.dwords)); p.image_id = id;
+	p.desc_digest = digest; p.gen = gen;
+}
+// Writes key K into table T (at its own way if present, else at the victim) - what a table of that shape does after
+// its own miss; `found`/`slot` from the lookup's candidate.  Drop = the same table's reaction to a stale detection.
+static void R1Fill(R1::Census& c, int t, uint64_t h, bool found, uint32_t slot, uint64_t rk, const uint32_t* dwords,
+                   ImageId id, uint64_t digest);   // w4/w8: tag = R1Tag(h), use = ++c.clock; d16: gen = c.gen
+static void R1Drop(R1::Census& c, int t, uint32_t slot);   // w4/w8: use = 0; d16: gen = 0
+static void R1Reset(R1::Census& c, const RenderExecutorMemo& memo, uint32_t block, int frame) {
+	std::fill(c.w4.begin(), c.w4.end(), R1::Set4 {}); std::fill(c.w8.begin(), c.w8.end(), R1::Set8 {});
+	c.gen = c.gen + 1u == 0u ? 1u : c.gen + 1u;      // d16 entries of older generations read as empty
+	c.observed = {}; c.mark = {}; c.clock = 0; c.memo = &memo; c.block = block; c.frame = frame;
+	Common::FrameStats::Add(Common::FrameStats::Counter::R1Reset, 1);
+}

+// did not see (the knob was off for a whole frame), a different memo.  g_block is written before the arm's gates are
+// applied (gates.cpp PollSchedule), so an M->P switch always shows a new block to the first armed lookup.
+static R1::Census* R1Arm(RenderExecutorMemo& memo, int frame) {
+	const uint32_t block = Common::Gates::Detail::g_block.load(std::memory_order_relaxed);
+	if (!t_r1) { t_r1 = std::make_unique<R1::Census>(); R1Reset(*t_r1, memo, block, frame); }
```

#### 2.1.3 The three census calls

```cpp
+// Before t0.  Key miss: find K in each table with the FULL proof; in pre mode also take the liveness snapshot NOW,
+// at lookup time, as a table of that shape would (the real miss path may change image state).  Hit: nothing but the
+// self-sample decision - no real data is touched before a hit's t0.
+static void R1Begin(R1::Census& c, const Common::SlotVector<Image>& images, uint64_t rk, uint64_t h, bool key_match,
+                    ImageId real_id, const uint32_t* dwords) {
+	c.self = (R1Next() & 63u) == 0; const uint64_t s0 = c.self ? Common::FrameStats::NowNs() : 0;
+	c.cand = {}; c.real_before = real_id; c.post = false;
+	if (!key_match) {
+		c.post = (R1Next() & 1u) != 0;                          // 50/50, per key miss (5.3)
+		const uint32_t tag = R1Tag(h);
+		const uint32_t s4 = uint32_t(h & (R1::W4Sets - 1)), s8 = uint32_t(h & (R1::W8Sets - 1));
+		const uint32_t d  = uint32_t(h & (R1::D16Slots - 1));
+		if (int w = R1FindExact(c.w4[s4], &c.w4p[s4 * 4], tag, rk, dwords); w >= 0) {
+			c.cand[0] = {true, false, s4 * 4 + uint32_t(w), c.w4p[s4 * 4 + w].image_id, c.w4p[s4 * 4 + w].desc_digest};
+		}
+		if (int w = R1FindExact(c.w8[s8], &c.w8p[s8 * 8], tag, rk, dwords); w >= 0) { /* same for cand[1] */ }
+		if (c.d16[d].gen == c.gen && R1Same(c.d16[d], rk, dwords)) {
+			c.cand[2] = {true, false, d, c.d16[d].image_id, c.d16[d].desc_digest};
+		}
+		if (!c.post) for (auto& k : c.cand) if (k.found) R1Live(k, images);   // pre mode only
+	}
+	if (c.self) c.self_ns = Common::FrameStats::NowNs() - s0;
+}

+// After t1 on the hit path.  c == nullptr at r1cen 1 (timers only).
+static void R1Hit(R1::Census* c, uint64_t ns, const RenderExecutorMemo::Texture& slot, uint32_t index, uint64_t h) {
+	namespace FS = Common::FrameStats;
+	FS::Add(FS::Counter::R1HitN, 1);
+	if (ns != 0) { FS::Add(FS::Counter::R1HitNs, ns); FS::Add(FS::Counter::R1HitTimed, 1); }
+	if (c == nullptr) return;
+	const uint64_t s0 = c->self ? FS::NowNs() : 0;
+	const uint32_t tag = R1Tag(h);
+	const bool watched = ((c->observed[index >> 6u] >> (index & 63u)) & 1u) != 0;
+	bool fill[3] = {};
+	auto& s4 = c->w4[h & (R1::W4Sets - 1)];
+	if (int w = R1FindTag(s4, tag); w >= 0) s4.use[w] = ++c->clock;
+	else { fill[0] = true; if (watched) FS::Add(FS::Counter::R1W4Lose, 1); }      // the 4-way table lost a hit
+	/* same for s8 / R1W8Lose */
+	if (!watched) {                                     // the real slot was filled before the census watched it
+		fill[2] = true; FS::Add(FS::Counter::R1Cold, 1);
+		c->observed[index >> 6u] |= uint64_t(1) << (index & 63u);
+	} else if ((R1Next() & 63u) == 0) {                 // d16 inclusion (5.2): a watched real hit MUST hit d16
+		const auto& p = c->d16[h & (R1::D16Slots - 1)];
+		if (!(p.gen == c->gen && R1Same(p, slot.resource_key, slot.dwords.data()) && p.image_id == slot.image_id)) {
+			FS::Add(FS::Counter::R1Incl, 1); fill[2] = true;
+		}
+	}
+	if (fill[0] || fill[1] || fill[2]) {               // a table of that shape refills after its own miss; the answer
+		const uint64_t dg = R1DescDigest(slot.desc);    // it would store is the real memo's (r1_*_bad tests that
+		for (int t = 0; t < 3; t++) if (fill[t]) R1Fill(*c, t, h, false, 0, slot.resource_key, slot.dwords.data(),
+		                                                 slot.image_id, dg);    // equivalence on the miss side)
+	}
+	if (c->self) { FS::Add(FS::Counter::R1SelfNs, c->self_ns + FS::NowNs() - s0); FS::Add(FS::Counter::R1SelfN, 1); }
+}

+// After t1 on the miss path (key miss, or stale when `stale`).
+static void R1Miss(R1::Census* c, const Common::SlotVector<Image>& images, uint64_t ns, bool stale, ImageId id,
+                   const TextureCache::ImageDesc& desc, bool store, uint32_t index, uint64_t rk, uint64_t h,
+                   const uint32_t* dwords) {
+	namespace FS = Common::FrameStats;
+	if (stale) FS::Add(FS::Counter::R1StaleN, 1);
+	else { FS::Add(FS::Counter::R1MissN, 1); FS::Add(FS::Counter::R1MissNs, ns); }
+	if (c == nullptr) return;
+	const uint64_t s0 = c->self ? FS::NowNs() : 0;
+	if (stale) {
+		// K is in the real table with a dead image; wherever a shadow holds K it holds the same id (5.2), so no
+		// table of any shape would hit.  Locate K now (proof only) to mirror the drop/refill and check the invariant.
```

## 5. Ceiling formula and bound

### 5.1 Why the shadow's "would have hit" is the real hit's proof

A real hit (`:1473-1485`) requires: slot valid ∧ `resource_key` equal ∧ 32-byte T# `memcmp` equal ∧ the cached image
`try_get`-alive ∧ `registered` ∧ `!needs_rebind` ∧ `!depth_id` ∧ `info.data` and `info.extent` equal to the stored
desc's. The shadow decides a would-hit on a real key miss with exactly that:

1. **Key**: the tag (high 32 bits of `memo_hash`) is only a filter; the decision is `R1Same` — the stored 64-bit
   `resource_key` and the stored full 32-byte T# compared exactly (`R1FindExact`). No hash-only decision.
2. **Liveness**: `try_get(stored id)` + `registered` + `!binding.needs_rebind` + `!depth_id`, read **at lookup time,
   before the real miss path** in pre mode (the miss path's `FindImage` can free, insert or merge images), and the
   candidate image's `info.data`/`info.extent` snapshotted then.
3. **data/extent**: compared, after the miss path, with the `desc` the miss path just computed. `desc.info.data`
   (`{Base40, size}`) and `desc.info.extent` are pure functions of (T#, resource) computed at `:1635-1640`, and
   `FindImage` never writes them (`textureCache.cpp:2029-2113`: it writes only `source_first_level`/`source_size` via
   `ConstrainSampledSource` `:1189-1217`, and `view_info.base_level/base_layer` for overlap views `:2102-2107`). So
   this is the same comparison the real hit makes against its stored desc — and whether the stored desc really
   equals the recomputed one is exactly what the bad check verifies (the digest covers `data`/`extent`).

**Verification against what the real miss path computes (§7):** a would-hit claims that the table would have returned
`(stored id, stored desc)`; the real miss path then computes `(id, desc, store)`; the claim is true only if
`store ∧ id == stored id ∧ R1DescDigest(desc) == stored digest`. Any disagreement is `r1_T_bad`.

**Real hits** update the shadow by tag only (`R1FindTag`: LRU touch, or a loss + refill). A 32-bit tag alias there
only mis-books a `lose` (probability ≤ ways × 2⁻³² per hit ≈ 10⁻⁴ a frame); it never enters a would-hit. This keeps
the per-hit cost to one tag line per table instead of up to 8 proof lines.

### 5.2 Two invariants that make the shadow self-checking

* **Same id.** Every real store writes the same `(K, id, digest)` into all three shadows at the same moment; a shadow
  refill from a real hit copies the real slot's `(K, image_id, desc)`. So whenever the real memo and a shadow both
  hold K they hold the same image id. Hence a stale real miss (K present, image dead) cannot be a would-hit anywhere,
  and `R1Miss` checks the invariant on every stale lookup (`r1_incl`).
* **16 K inclusion.** `memo_hash & 16383` refines `memo_hash & 4095`: the storable accesses mapping to a 16 K slot
  are a subset of those mapping to its 4 K slot, drops are mirrored, so if the real slot holds K (last stored, not
  dropped) the 16 K slot holds K too. A watched real hit that misses the 16 K shadow is therefore a census desync,
  never a table property: `r1_incl` (sampled 1/64 with the full proof and the id). So there is no `r1_d16_lose`.
* **Watched slots.** Losses are counted only on real slots whose content the census saw being filled (`observed`
  bitmap); a real hit on a slot filled before the last reset is `r1_cold` (a compulsory shadow fill), not a loss.

### 5.3 The warming control (pre/post mode)

The pre-miss liveness read touches the lines of exactly the image the real miss path's `FindImage` will find for a
would-hit lookup, so it would bias the would-hit lookups' miss time LOW (by up to a few cache misses, ≤ ~0.1–0.3 µs
[I]) and the ceiling low — the wrong direction for an upper bound. Each key miss therefore draws a mode (50/50,
`R1Next`): **pre** (liveness before the miss path — the exact semantics; its miss time is warmed) or **post** (only
census-private proof lines read before t0; liveness read after the miss path; its miss time is unwarmed, its decision
approximate). The ceiling takes the **count from the pre half** (exact decisions, scaled by the known sampling ratio)
and the **price from the post half** (unwarmed). The two halves are random halves of one population, so their
would-hit rates must agree (fixture F4); the pre-vs-post mean miss time of would-hits is the measured warming effect,
reported.

### 5.4 Formula (per table T ∈ {w4, w8, d16}; Σ = sum over the window frames of the P arm; N_f = their number)

```
t_hit   = Σ r1_hit_ns  / Σ r1_hit_t                    [M]  mean hit-path price
t_miss  = Σ r1_mp_ns   / Σ r1_mp                       [M]  mean unwarmed key-miss price
W_T     = Σ r1_T_q · Σ r1_mn / (Σ r1_mn − Σ r1_mp)     [M]  would-hits (exact pre half, scaled to all key misses)
t_T     = Σ r1_T_pns / Σ r1_T_p                        [M]  unwarmed miss price of would-hit lookups
A_T     = W_T · (t_T − t_hit)                                the conversion miss -> hit       (the task's formula)
L_T     = Σ r1_T_lose · (t_miss − t_hit)                     hits the shape would lose      (L_d16 = 0)
R_T     = Σ r1_T_rb · (Σ r1_rb_ns/Σ r1_rb_n − Σ r1_rbf_ns/Σ r1_rbf_n)   texfast re-records avoided (<= 1 per fill)
C_T     = (A_T − L_T + R_T) / N_f / 1000               µs a frame
C_R1    = max_T C_T                                    the R1 ceiling; also report A_T/N_f alone and each term
```

2SE of `C_T`: across blocks (compute `C_T` per P block, standard error of the block values), as the program's other
per-block ceilings.

### 5.5 It is an UPPER bound

`C_T` over-states what a real memo of shape T could remove, because it omits, each with a known sign:
* the extra probe of an N-way lookup on EVERY lookup (≈ 48.9 k a frame × a few ns) — minus;
* a 16 K table's 4× footprint (16 384 × ~650-byte `Texture` entries ≈ 10.6 MB) slowing the 47 k hits — minus;
* `t_hit` is the mean over all real hits, whose entries are hot; a would-hit hits an entry the direct table evicted,
  i.e. a colder entry — minus;
* `R_T` counts the first re-record after every would-hit fill, even when the view the bigger table kept would have
  been stale (`bind_stamp` moved) and re-recorded anyway — minus;
* `r1_cold` hits are not counted as losses (`L_T` low) — minus.

What could push it low, and how it is handled: the warming bias (removed by pricing with the post half, §5.3); shadow
warm-up after a reset (the first 1–2 frames of each P block, outside the window 10–88); census cache pollution in the
P arm inflates both `t_miss` and `t_hit` (sign of the effect on `t_miss − t_hit` ambiguous, stated as a limit; the
self cost in §6 bounds it). Noise: 2SE.

## 6. Own cost and how the scorer separates it

The census's own work never enters `C_T`: every census call sits outside `[t0, t1]` (pre-work before `t0` in
`ResolveTextureWith`, bookkeeping after `t1`; `RebindImages` does its Adds after the loop), and the stamp latency
cancels in every difference.

Estimated P-arm cost (r1cen=2) [I]:

| item | a frame | unit | µs a frame |
|---|---:|---:|---:|
| knob read at every call (BOTH arms, also at 0) | ~48.9 k + ~9.4 k `RebindImages` | ~0.3 ns | ≤ 20 |
| `Enabled()` + branches + RNG | ~48.9 k | ~3 ns | ~150 |
| hit stamps (1/8) | ~5.9 k × 2 | ~5 ns | ~60 |
| key-miss stamps | ~1.8 k × 2 | ~5 ns | ~20 |
| `R1Hit`: 2 tag lines (64 KiB, L2) + LRU writes + bitmap | ~47.1 k | 8–15 ns | 380–710 |
| sampled d16 inclusion (1/64) | ~0.74 k | ~40 ns | ~30 |
| `R1Begin` on key misses: ≤ 3 proof lines (+ image lines in pre mode) | ~1.8 k | 60–150 ns | 110–270 |
| `R1Miss`: digest (~73 words XXH3) + 3 fills | ~1.8 k | 60–150 ns | 110–270 |
| loss / cold refills (digest + fill) | 0–1 k | ~80 ns | ≤ 80 |
| `RebindImages` stamps (re-record all, fast 1/16) | ~(1.5 k + 2.8 k) × 2 | ~5 ns | ~45 |

the window); each reset ≈ 64 KiB of `fill` (~10 µs).

**Separation.**
1. **ABBA P−M** (P: `r1cen=2`, M: `r1cen=0`, the program's estimator, frames 10–88) on `dt_us` and `cpu_gpu_us` gives
   the price of ALL session-120 P instruments together (R1 + `spcen` + R2). Reported, not a verdict input.
2. **R1's share** = `Σ r1_self_ns / Σ r1_self_n × Σ(r1_hn + r1_mn + r1_sn)` + stamps × 4.2 ns (`cbmove` s101: a mark pair
   8.35 ns), stamps = 2·(`r1_hit_t` + `r1_mn` + `r1_rb_n` + `r1_rbf_n`) + 4·`r1_self_n` [I for the stamp price].

   loop) — a cross-check of item 2.
4. Consistency flag (informational): R1's share > ABBA Δ`cpu_gpu_us` + 2SE ⇒ report "self-cost inconsistent".

## 7. The bad check (must be 0)

`r1_w4_bad`, `r1_w8_bad`, `r1_d16_bad` — counted in `R1Miss` on every would-hit (pre and post mode) of that table:

```
bad  ⇔  would-hit ∧ ( store == false                     // the real path would not even memoize this answer
                     ∨ cand.id != id                      // a different image (index or generation)
                     ∨ cand.digest != R1DescDigest(desc)  // a different desc: data, extent, formats, view, source trim…
                   )
```

with `R1CenMismatch: table= post= store= id_same= desc_same= addr=` (≤ 40 lines a process).

Meaning: a table of shape T would have returned an answer the real resolution disagrees with. Any `r1_*_bad > 0` in
the window ⇒ **R1 FAIL** ("a bigger memo is unsound as designed"), whatever the ceiling — the rule of the program
(ROADMAP s120 item 1: all `*_bad` = 0). Because the real memo's own hits follow the same semantics, a nonzero value also
says the EXISTING memo can return a stale answer; the session that sees it records that before anything else.

Coverage: exact in the pre half. In the post half a bad whose miss path freed the shadow's image is invisible (post
liveness fails); with ≈ 0.9 k pre-mode key misses a frame × ~3 000 window frames ≈ 2.7 M exact checks a run, any
disagreement mechanism above ~10⁻⁶ per key miss shows in the pre half.

Separate validity counter (not "bad", but the census is NOT_EVALUABLE if nonzero): `r1_incl` (desync — the shadow did
not see all traffic: schedule/gate toggles within a frame, another thread, a bug).

## 8. What must NOT change at r1cen = 0 (and at 1 and 2)

At 0:
* `ResolveTextureWith`: control flow, every existing Add and its order (`texmemo_*`, `tex_hits`, `tnull_*`), the
  `bindwit` marks, the memo's contents/`version`/`fast_view`, the emit arguments — unchanged. Added: one relaxed knob
  load (`Value`, `gates.h:642-647`) per call that reaches the memo, and three never-taken branches.
* `RebindImages`: texfast decisions, counters, records unchanged. Added: one knob load per call (only when `fast`),
  never-taken branches per binding.
* No census allocation, no thread-local access, no `NowNs`, no `Enabled()` call (short-circuited).
* No layout change: `RenderExecutorMemo`, `Texture`, `TextureBinding`, `RenderExecutor` untouched; the census is a
  file-static `thread_local` in `descriptors.cpp`; `render.h`/`renderMemo.h` unchanged.
* Nothing under `src/graphics/shader/**` (the translation-cache signature does not move).
* `FrameTrace-x` gains 39 names at its end (existing scorers read by name; the line gets longer).

At 1 and 2 (behaviour still unchanged): the census reads image state only via `SlotVector::try_get` (const) and
fields; takes no lock (`m_lock` untouched, no `TouchImage`, no `FindImage`); writes only its own memory and counters.
It changes timing (that is what the ABBA prices), allocates 1.6 MiB once (level 2), and must run with `bindwit=0` for
sampled hits (enforced in code: hits in a `bindwit`-armed slot are never timed) and `texfastcheck=0`.

## 10. Pre-registered verdict (to go into ROADMAP before code)

* **FAIL** — any `r1_w4_bad`, `r1_w8_bad`, `r1_d16_bad` > 0 in a window row: R1 unsound as designed; no track.
* **NOT_EVALUABLE** — F1/F2/F3/F5 fail, or F4 fails, or `r1_incl` > 0, or > 25 % of P blocks dropped.
* **OPEN** — `C_R1 ≥ 1 000 µs` a frame (point estimate), all bad = 0, evaluable: the R1 track opens (its design and
  first seal go into `next-session-121.md`; the table shape is the argmax T).
* **CLOSED** — `C_R1 + 2SE < 1 000 µs`: R1 closed on Sky Garden (together with the other two instruments' outcomes this
  decides whether the GuestGpu micro-tracks there are exhausted).
* **BORDER** — otherwise: recorded as "not opened"; the only admissible follow-up is a rerun, never a reading-level
  argument.
* Reported beside the verdict, never as a gain: `A_T`, `L_T`, `R_T` per table, W_T, t_hit, t_T, the warming effect
  (pre − post mean miss time of would-hits), the instruments' ABBA price and R1's self share. A would-hit is a ceiling,
  not a speed-up.

## 11. Adversarial notes and risks

* **Coordination with R2.** R2's resolve-time interval (if it brackets the `PrepareBindings` image loop) contains all
  of R1's census work in the P arm (~15–25 ns a slot [I]); the R2 scorer must subtract R1's self share (`r1_self_*`)
  or R2 must run in an arm without `r1cen`. Same for any `bl_res_us` reading.
* **Loss refill model.** A shadow refill after its own miss on a real hit stores the real memo's answer, not an
  independent resolution (running `FindImage` would have side effects). This is exact whenever `r1_*_bad = 0` on the
  miss side (the same equivalence).
* **Reset detection** relies on `Gates::Detail::g_block` (a new block at every schedule boundary, written before the
  arm's gates) and on `GetFrameNum()` gaps. A gate-FILE toggle of `r1cen` inside one frame can desync the shadow; it
  shows as `r1_incl` (sampled). The sealed run uses the schedule.
* **P-arm slowdown ~1 ms** changes the scene's pacing a little; populations are per GuestGpu frame, so the census is
  comparable across frames; the verdict uses P-arm frames only.
* **Tag width.** 32-bit tags: aliasing is caught by the exact proof on key misses (`r1_tagx`); on real hits it can
  only hide a loss (≈ 10⁻⁴ a frame).
* **Not modelled:** a bigger table's own `memo_index`/`version` semantics for texfast (only its upper effect, `R_T`),
  and the cost of an N-way probe (omitted, §5.5). If R1 opens, those belong to the build of the real table, whose ABBA
  is the only speed number.
* **The prediction says CLOSED or BORDER** (≈ 0.7–0.85 ms [I]); the census is still worth its build because it closes
  R1 by measurement and says which shape, if any, came nearest.
