Run level: the seal pinned (`DRAFT`/`SEAL`), the installed binary = the build above (`IDENTITY`), the entries in
launch order (`ORDER`), all inputs present (`INPUTS`). Per entry: binary recorded = the build (`BINARY`), prereg
sha/bytes (`PREREG`), `KYTY_PIPELINE_PRECACHE=gfx` (`ENV_PRECACHE`), `KYTY_GPU_CLOCK_PIN=1` (`ENV_PIN`), no
`KYTY_GATE_SCHEDULE`/`KYTY_GPU_CHECKPOINTS`/`KYTY_REC` (`ENV_FORBIDDEN`), the gate text ends with its arm's token and
lacks the other (`GATES_ARM`), exactly one ok attempt with no hold exit and ≥ 142.5 s held (`ATTEMPT`), exactly one
`GpuClockPin: mode 1` (`PIN_ONCE`), `PipelinePrecache` queued 0 compute pipelines (`PRECACHE_OFF`), no failure
marker (the `run_safety99` tokens plus `--- Error ---` and `AsyncPipelines: skipped draw`; `NO_MARKER`), ≥ 1 000
`FrameTrace-x` rows each carrying all six counters (`ROWS`), arm A dark (Σ`cspfam_skip` = Σ`cspfam_look` = 0;
`ARM_A_DARK`), arm B armed (Σ`cspfam_skip` > 0; `ARM_B_ARMED`).

## 4. Rule

S = Σ(`cs_sync_new` + `cs_sync_wait`) over ALL `FrameTrace-x` rows of an entry (the load included); S_A, S_B the sums
over each arm's four entries. **NO_POWER** if S_A = 0 (no exposure: v2 is not taken further on this run).
**PASS** if S_A > 0 and S_B ≤ S_A + 2. **FAIL** otherwise. On PASS: the frame-time ABBA `fam109` (its own seal).
On FAIL: v2 closed as designed; the record goes to ROADMAP before anything else.
