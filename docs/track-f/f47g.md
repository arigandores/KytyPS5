## 3. Что измерено и что нет (причина)

| величина | источник | точно / нет |
|---|---|---|
| (i) образа | чтение через алиас бэкинга (`TryGetBackingPointer`, иначе `TryReadBacking` / `TryReadPrtBacking`) — без сбоя страниц, без синхронизации | ✓; GPU-модифицированный образ (`gpumod=1`) — ридер «не определено» (содержимое — продукт ГП) |
| источник (ii), `staging` inline | байты копии в кольце staging после копии | **точно** (`sexact=1`) |
| источник (ii), `staging_async` (пул) | хэш, когда отметка завершённых копий пула ≥ очереди на момент ноты, а поколение кольца staging то же (`StreamBuffer::Generation()`); **не ждётся никогда** | точно; иначе `lost` / `pending` (+ `srcres`) |
| источник (ii), `import` | хэш импортированных страниц гостя в момент записи команды; запись CPU в эти страницы ждёт чтения ГП (`RenderContext::HandleFault` → `WaitPendingHostReads`) [c кода] | `sexact=0`, `swhy=import_at_record`; запись, минующая обработчик сбоя (чтение файла в алиас бэкинга), — [I] |
| источник (ii), `owner` / `gpu` | байты в буфере ГП | **не измерено**: без чтения ГП (смена синхронизации) не измерить — `swhy=gpu_buffer_bytes` / `gpu_modified_range` |
| буфер, `cache_buffer` | байты в буфере кэша ГП | **не измерено** (`gvh=unmeasured:gpu_memory`); `ring_copy` — точно |
| SRT «гость сейчас» | повторная материализация того же плана (`MaterializeResources`) читателями `TryReadBacking` / `TryReadGpuCleanBacking` без кэша чтений и без счётчиков; план — из `ProgramCache::Get` | ✓; первый draw новой программы (план появляется при компиляции в этом вызове) — `fresh=unmeasured:no_plan` |
| регистры | тень сырых слов на разборе PM4 | ✓ для `SET_CONTEXT_REG` / `SET_CONTEXT_REG_INDIRECT` и Clear/Push/Pop/Reset; копии состояния процессора проверкой «spine» (гейт, умолчание выкл.) тенью не отражаются [I] |
| состояние Vulkan | ключ пайплайна draw (копия из `CreateGraphicsPipelineLocked`), факторы — обёртками `shaders.cpp`; альфа-факторы при `separate_alpha_blend = 0` — как в `shaders.cpp` (= цветовые); динамика — пересчёт теми же функциями, не перехват команды | ✓; перепись dual-source (`DualSrcBlend`) в строке не отражена; константы смешения не печатаются |

**Побочные эффекты `=1` (только измерение):** повторная материализация проходит `MaterializeSnapshot` — его `thread_local` scratch меняет ёмкость, а
метка `FrameStats` `MatEvalNs` (при включённом сборе времени) получает второй вклад; порядок, синхронизация, кэши образов / буферов / пайплайнов и
память гостя не меняются (нет `Touch`, ожидания, чтения ГП). Хэширование, файлы и материализация идут на потоке GuestGpu под мьютексом рендера —
кадры при `=1` дольше [I величины]. **Вопросов лиду нет:** ни одному полю не понадобился путь, меняющий поведение; поля без такого пути — «не измерено»
с причиной (таблица).

`ROP3`), окно 0, свои ножницы (экран ∩ окно ∩ общие ∩ окно вывода при `VPORT_SCISSOR_ENABLE`, смещение окна при сброшенном `WINDOW_OFFSET_DISABLE`,
зажим экстентом), глубина, отсечение, alpha-to-mask) и чтение правила (6) по спискам показов чёрной и белой серий: проверка файлов, Н±, П1 (подписи
