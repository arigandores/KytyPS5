## 3. RC2 — лист `OTHER_BR` и В4 по выводу (п. 722(в))

### 3.1 Правило

В программе с условной ветвью, обратной ветвью или записью `exec` пере-оценка §3.3 издания 3 добавляет живой вход каждого регистра среза. Издание 4
различает:

| лист | когда | класс |
|---|---|---|
| `OTHER_BR` | живой вход VGPR PS, у которого в программе **раньше места использования** есть определённое (не «слабое») определение этого регистра — в прямой программе поиск закончился бы на нём | по В4 |
| `OTHER` | живой вход VGPR без такого определения (барицентрики, `FragCoord` — настоящий вход), LDS, `lds_direct`, `TTMP`, `M0` как данные, `s_getpc` / `s_getreg` / `s_memtime`, неизвестная кодировка, живой вход SGPR выше user data в прямой программе | «не определено» |

**Чтение класса (п. 721(д), 722(в)):** C-imm ⇔ листья ⊆ {`LIT`, `COV`}; иначе `IMG` ⇒ T; иначе `OTHER` ⇒ «не определено»; иначе лист C-buf ⇒ C-buf;
иначе «не определено». Поле `v4 1` печатается у точки, если класс C-buf / T и среди листьев есть `OTHER_BR` — «класс прочитан по В4». `OTHER` при любом
наборе без `IMG` ⇒ «не определено»; `IMG` с `OTHER` ⇒ T, каждый вход по М2 — форма издания 3 (§2: шаг 4 раньше шага 6); строку п. 722(в) «`OTHER`
при любом наборе ⇒ «не определено» как раньше» издание читает так; иное прочтение — вопрос В5(б) лиду. В4 `НЕ ДЕФЕКТ` не открывает: точка идёт в (в)(5).

**Граница `OTHER_BR` [I]:** «есть определение раньше» — по порядку программы, без доминаторов; если ветвь обходит это определение, а живое значение
регистра реально доходит до экспорта, `OTHER_BR` скрывает настоящий вход. Это читается только в сторону (в)(5) (класс по C-buf / T), не в сторону
`НЕ ДЕФЕКТ`; в «Не заявляется».

### 3.2 `OTHER_BRS` — вопрос В5(а)

Пере-оценка добавляет и живой вход SGPR выше `user_data_count`, когда у SGPR есть раннее определение (типично — результат `s_load`, по которому идёт
ветвь). п. 722(в) называет только VGPR, поэтому издание печатает отдельный лист `OTHER_BRS` и **читает его как `OTHER`** (буква); поле `b5` — класс
при прочтении `OTHER_BRS` как `OTHER_BR` — справка, не исход. На корпусе T1 оба прочтения дают одинаковое распределение (`b5` = классу у 141 из 141).

у программы D_b с udc < номера SGPR загрузки В4 по букве почти не применим. Член п. 718(г)(5) от этого не меняется (m2 «не C-imm» с `SMEM`).

### 4.1 Вид `Shader Out` — член К-вид в F47e (п. 722(г)(1))

(прочтение Q1: приведённое к формату). **К-вид** (член положительного контроля F47e, на каждом снимке, до первой точки C-imm этого снимка):

- событие снимка, у которого экспорт цели UNORM8 известен (программа C-imm по `cls_f47a4.py`) и хотя бы одна компонента литерала **не представима
  в UNORM8 точно** (v·255 не целое); `Shader Out` = литерал (|Δ| < 2⁻²⁰) ⇒ вид Q0; = round(v·255)/255 ⇒ вид Q1; иначе К-вид «не определено»;
- или П2 (класс T) на цели UNORM8: хоть одна компонента `Shader Out` из ≥ 16 точек не кратна 1/255 (|v·255 − round| > 2⁻¹²) ⇒ Q0; все кратны при ≥ 8
  различных значениях компонент ⇒ Q1; иначе «не определено».

**До ответа К-вид (и при «не определено»)** (а) читается при обоих прочтениях: «равно» — если равно хотя бы при одном в допуске В2 (≤ 1 младшего
разряда формата цели: UNORM8 — 1/255, float16 — ulp float16 в точке), «не равно» — только если различие **при обоих** > 1 младшего разряда, иначе
«не определено». После ответа — только названным прочтением, с тем же допуском.

### 4.2 Сопоставление компонент (п. 722(г)(2))

  сырого слова нет ⇒ требование к коду звена (в)(5) — §6.

## 8. Вопрос лиду (решение не принимается этим изданием)

- **В5.** (а) `OTHER_BRS` (§3.2): живой вход SGPR выше user data, добавленный только пере-оценкой при ветвлении, — тот же механизм, что `OTHER_BR`, но
  п. 722(в) называет только VGPR. Рекомендация: читать `OTHER_BRS` как `OTHER_BR` (поле `b5` становится классом) — иначе В4 не применим к ветви по
  результату `s_load` в SGPR выше udc (m2 Н4 — пример); `НЕ ДЕФЕКТ` это не открывает (точка идёт в (в)(5)). До решения — буква: как `OTHER`.
  (б) Строка «`OTHER` при любом наборе ⇒ «не определено»» читается в форме издания 3 (`IMG` с `OTHER` ⇒ T, вход `OTHER` — по М2, т. е. не измерим);
