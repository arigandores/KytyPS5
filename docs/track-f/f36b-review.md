## 3. Требуемые изменения

**RC1. Член RC4(б) F23g в наборе F36a не исполнялся.**
Что не так: п. 503(в) делает члены RC1–RC4 F23g обязательными «для любого будущего реплея Б8» (`02531a91:docs/ROADMAP.md:22845`,

читаемом к «не найдено», — плечи `mask_inv`, `mem_inv`, обязанные совпасть с `sens` побайтно и отличаться от `def`»
(`f22eccf5:docs/track-f/f23g-review.md:157`, якорь «обращённым контролем [c, §2]. Изменить: любое отрицательное `N` любого плеча»;
+1 — «на каждом событии, читаемом к «не найдено», — плечи `mask_inv`, `mem_inv`»). Набор F36a — плечи `orig`, `def`, `mask`, `mem`,
`sens`, `diag`, `orig2` (`08214036:docs/track-f/f36a.md:136`, якорь «- **Набор:** все 38 событий описи, все плечи»; +1 — пустая
строка); исполнение опор подтверждено только `bound_ok` (sha отражения). RC4(а) соблюдён (`tot` → −1, член Г1 `v == 0` его
отбрасывает — `08214036:docs/track-f/f36a/sum_f36a.py:55`, якорь «m.append(('G1', all(v == 0 for v in e['Npre'].values())))»; +1 —
«m.append(('G2', e['n_entry'] == e['PSInv']))»).
Сценарий отказа: реплей не применяет пайплайн опоры (отражение показывает подменённый модуль, исполняется прежний код) → `mask` =
`mem` = `def` побайтно → `N_diff` 0 на всех 13 событиях без исполнения опоры → кандидат (3)(а) на пустом сравнении.
Сейчас: опровергнуто своим реплеем на **13 из 13** годных событий [c, §2]: `N(sens, mask_inv)` = `N(sens, mem_inv)` = 0 и `N(def, ·_inv)`
= `sens` (228–1 019) — обе опоры исполняются и видят все три места; плюс m3 (§5) — опора с одной ошибкой select отличается от
`mask` на 13 из 13. Изменить: F36c читает член RC4(б) по F36b §2 (не по F36a) и пишет в строке исхода «RC4(б) — [c F36b], 13 из 13»;
отчёт F36a §0.6 члена не несёт — строкой «не исправлено, читать так». Новых прогонов не требуется.

**RC2. Г1 F36a — только выходы; «состояние до события» п. 687(е)(1) шире, и прошлое исполнение доходит до события через входы.**
