## 4. Находка: сторож T306 обходится свёрткой обёртки при константной маске выборки [c кода и IR]

`Translator::IMAGE_SAMPLE` при `T306=1` подставляет смещение как `SelectU32(exec выборки, offset, 0)`; `MResolveSampleOffset` узнаёт обёртку как
**первый** `SelectU32` на пути. Начальный `exec` — константа `true` у всех стадий, кроме пиксельной, и у compute, кроме волны 64 на подгруппе 32 с
числом потоков, не кратным 64 (`Translate.cpp`, `initial_exec`, `entry_ir.SetExec(initial_exec)`). Если выборка идёт под этим `true` (вход или
`s_mov_b64 exec` с сохранённого входного значения), `SelectU32(true, offset, 0)` сворачивается, и на месте обёртки оказывается **запись**
`SelectU32(A, 0x0101, old)`: сторож читает `exec := A`, `inner := 0x0101` — константа, `ConstOffset` всем дорожкам. IR формы `full` (дамп
`spv3/1.spv.ir.txt`, `=1`):

```
%10 = UGreaterThan32 %9, 0x00000000          ; A = s8 > v0
%11 = SelectU32 %10, 0x00000101, 0x00000000  ; запись смещения под A (обёртки T306 нет - свернулась)
%14 = MakeImageAddress %11, ...
ImageWrite %17, %18, %19, true               ; exec выборки/записи = true
```

Итог: `=1` — `ConstOffset=1` и на `main`, и на мутанте (проба печатает `probe full-mask … ConstOffset=1`); дорожки вне A получают (+1, +1) вместо
своего старого смещения. Это сценарий RC-T306-1 «смещение под частичной маской, выборка под полной», утверждение отзыва «правильный код идёт
прежним путём» для константной полной маски неверно. Отличить свёрнутую обёртку от записи по IR нельзя (у обеих ложная ветвь может быть 0 —
здесь старое `v20` = 0), поэтому правка — в коде темы (например, обёртка, которую свёртка не снимает), это вне этого звена (код темы не меняется).
Достижимость в игре: программы с `image_sample_*_o` вне пиксельной стадии или пиксельные с `exec` = литерал `-1` после частичной записи смещения —
[U] (корпус T1 не размечался). Тест при правке: проба `full` становится `Check` (`ConstOffset == 0` при `=1`).

**Вопрос лиду (решение не моё):** T306 в MS1 при этой находке — `CAUGHT` M2c2 закрывает только RC-T306-1 по букве (мутант `t306_mask`);
варианты — правка темы новым звеном до M2c2, или MS1 без T306 (маска `0x33`, п. 761(з)).
