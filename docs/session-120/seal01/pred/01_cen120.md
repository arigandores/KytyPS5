## Rules

The formulas, admission, controls, correctness rules and verdict ladder are those of `design120.md` (sha256 recorded
in `SEALS120.txt`, git `docs/session-120/design120.md`) sections 2–6, including the section-4 blocks added by the code
review (timer-read add-back in `N⁺`, row-skew tolerance), as implemented by the two scorers. In short:

- Window: positions 10–88 of every block, `draws > 3000`; pairs = consecutive P, M blocks of the ABBA sequence; 2SE
  from per-pair values (package: per-pair sums); correctness counters and mismatch lines over ALL rows.
- **R1** (P arm): `C_R1 = max_T C_T`, T ∈ {w4, w8, d16}, `C_T = (A − L + R + E − P)/N_f`; point = upper.
- **R2** (M arm, `r2_s_*` are subsets): `C_up` (traced), `C_pt` and `C_lo` (play), `C_rp`/`C_ext` information.
- **Package R**: `R_pt = C_R1 + C_R2,pt`, `R_up = C_R1 + C_R2,up`.
- **spcen** (P arm, M for the warm deltas): point `N = N_A + N_B`; upper `N⁺` with the add-back
  `Z = z̄·(2·sp_rt_n + sp_rt_rec + 2·sp_tr_n)`, `z̄` from `r2_nul` of the P window, and `Δ_A`, `Δ_B′`.
- **Verdict** per member and package: FAIL (any correctness counter or mismatch line) > NOT_EVALUABLE (admission,
  identity, sampler, control, sanity) > **OPEN** (point ≥ 500 µs a frame) / **CLOSED** (upper + 2SE < 500 µs) /
  **NOT_OPENED** (otherwise).

## Consequences (ROADMAP s120 item 4, verbatim in substance)

- OPEN: a speed track opens for the carrying member(s) (R: the argmax table shape of R1 and/or the swap-held R2 reuse;
  SP: the same-pass render-target memo and/or the transit skip); the prototype has its own verify gate and ships only
  by ROADMAP s120 item 2(в). A would-hit is a ceiling, not a speed-up.
- CLOSED: that path is recorded exhausted on Sky Garden at the 0.5 ms rule.
- NOT_OPENED: recorded; the only admissible follow-up is a rerun, decided at the close.
- FAIL: the mechanism is unsound as designed; a nonzero R1 or R2 bad also says the EXISTING memo may return a stale
  answer — the next session starts there.

## Member verdicts and scorer specifics (recorded after the pre-seal check, before the seal)

- Every member is judged alone by the same ladder and carries its own consequence (design120 §6 "each member
  reported alone with the same rule"; ROADMAP s120 item 4 "каждый член отдельно — тем же правилом"; spcen review
  "N_A alone ≥ 500 ⇒ OPEN and names A"): a member OPEN opens that member's track even when its package is
  NOT_OPENED, or NOT_EVALUABLE through the other member; a member CLOSED records that member's path exhausted.
  Both scorers print one consequence line per member; each scorer's summary `CONSEQUENCE:` is FAIL if any member
  fails, else NOT_ADMITTED if not admitted, else OPEN naming the OPEN member(s) when any member or the package is
  OPEN, else the package's own consequence. rpk120: per-name lines `CONSEQUENCE: R1|R2|R …`, the package line names
  `Open members:` (never a NOT_OPENED member; `R1+R2 (together)` when only the package is OPEN) and, when the package
  is not OPEN but a member is, says it is superseded for that member; the summary line is the last line.
- Pairs are formed only from blocks whose later block reached window position 88 (both complete, as rpk120); a
  partial last block feeds the controls only. The last main `FrameTrace` line of the log is exempt from
  STREAMS_COMPLETE when its `-draw`/`-x` line is missing or cut (as g2_119 / rpk120).
- Point values are pooled: Σ over the estimator frames of all paired blocks of an arm / their frame count (not the
  mean of block means; blocks carry about equal frame counts). 2SE from the per-pair values.
- spc120 tolerances (the scorer's own choice, named here): draw identity `sp_rt_n` vs `pl_em_n` within ±64 per P
  block window and ±256 over the whole P window (smoke: largest block 11, total −33); emit chain
  |mean Σ(8 `pl_em_*` parts)/1000 − mean `mh_emit_us`| ≤ 256 µs A FRAME in each arm (a time tolerance, not the
  s116 count tolerance; smoke offset ≈ 108 µs in both arms); reason partitions and count nestings **±8 per block
  window in both scorers** (ROADMAP s120 item 6, the lead's decision before the seal, replacing ±2 of item 5: on the
  smoke the `sp_tr` partition reached ±2 — no headroom; a persistent off-by-one gives ≥ 79 a window and still fails);
  ns/slot/target/Kpx nestings within the subset's values on the block window's first and last lines.
- `bl_tr_alive` and `a_den` read the paired estimator frames (they guard the formula denominators).
- RC5(d)/RC4 "CLOSED if mean(G⁺) < 500" and "G⁺ = 490 ⇒ CLOSED" are NOT implemented: design120 §6 (CLOSED on
  `N⁺` + 2SE) governs; G and G⁺ are reported only.
- RC5(a) nesting `sp_rt_rec_ns ≤ pl_em_sppost_ns + rec-span share` is not tested (no counter carries the share);
  `sp_tr_rec_ns ≤ sp_tr_post_ns` is.
