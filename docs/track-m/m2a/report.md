## 2. Что сделано по темам (решения исполнителя — на проверку M2c)

- **Ручки.** `KYTY_M_T234`, `KYTY_M_T233`, `KYTY_M_T256`, `KYTY_M_T306`, `KYTY_M_T032`, `KYTY_M_T203`; умолчание 0 (не задана, пусто, `0/false/off/no`
  — выкл.; иное — как `Common::EnvValueOn`); читаются один раз за процесс (`Decoder::MThemeMask`). Подпись трансляции и каталог варианта: одна
  метка на волну `:mw1_<маска>` / `_mw1_<маска>` последней (бит = номер темы), при всех `=0` метки нет — у MS1 с умолчаниями `=1` подпись
  меняется один раз. Строка журнала `MWave1: mask=… T234=… …` (конструктор кэша трансляции). Таблицы `Gate`/`Knob` не трогались,
  `check_gate_order.py` — `GATE ORDER: clean` на worktree и `main` (вывод = FS15a).
- **Подпись при `=0`.** Правка в `src/graphics/shader/**` меняет хэш исходников транслятора ⇒ подпись меняется и при `=0` (кэш холоден у
  любого бинаря с этим кодом); при этом SPIR-V при `=0` = FS15 байт в байт (члены выше).
- **T234.** Декодер при `=1`: `DS_MIN/MAX_F32` — 2 источника (адрес, DATA0); транслятор при `=1` не читает DATA1 (третий аргумент IR = DATA0,
  арность опкода IR не менялась); эмиттер при `=1` — `EmitDsFloatAtomicReplacement` (форма upstream `e85279ea`: NaN-операнд даёт другой,
  sNaN глушится, отрицательные денормали равны −0, положительные — между собой, при равенстве min берёт источник, max — старое).
- **T233.** Декодер не менялся (VOP2 `0x2b`–`0x2d` у нас — те же `V_MAC/MADMK/MADAK_F32`): слитность решается по сырому опкоду
  (`opcode_id & 0xff ≥ 0x2b` ⇒ FMA). Новый опкод IR `FPMad32` — последним в `ValueOpcodes.inc` (номера плана кэша не сдвигаются), в списке
  чистых операций `PredicationElimination`. Эмиттер: `OpFMul` + `OpFAdd` с `NoContraction`; сброс денормалей — `EmitFlushF32DenormToSignedZero`
  (по нашему режиму `DenormFlushToZero`: при FTZ/«assume» — без явного сброса); закомментированный вариант T237 не берётся.
- **T256.** Режим 6 — `UnpackSnorm2x16` (upstream); режим 8 при не-uint выходе — сырой путь со знаковым извлечением 16-битных половин (как режим 7
  с беззнаковым) — шире upstream по формулировке п. 756(в)(1) «6–8»; режим 7 уже был верен.
- **T306.** При `=1` транслятор отдаёт слово смещения выборки (адресное слово 0) как `SelectU32(exec выборки, смещение, 0)`; эмиттер
  (`MResolveSampleOffset`) принимает смещение как константу, если это непосредственное значение, эта обёртка вокруг непосредственного или вокруг
  `SelectU32(c, imm, old)` с тем же `c` (запись VGPR под той же маской) — тогда `ConstOffset` точен для каждой активной дорожки. Иначе (смещение,
  записанное под другой маской, вычисляемое), а также куб и компонента вне `[−8, 7]` — **прежний путь (смещение не передаётся) и строка
  `MTexOffset:`**, трансляция не роняется. Gather не менялся (у него смещение уже передаётся). Upstream вместо этого добавил exec-аргумент в
  `ImageSampleRaw`/`ImageGatherRaw` — у нас это сломало бы `=0` байт в байт.
- **T032.** Кодирование компоненты по формату V# — форма upstream `de9c15fa` (UNORM/SNORM: NaN → 0, зажим, масштаб, `RoundEven`; USCALED/SSCALED:
  NaN → 0, зажим, усечение; 2-битные каналы беззнаковые; FLOAT16 — `PackHalf2x16`). **Отличие от upstream [I]:** не упакованные форматы пишут
  только переданные компоненты, каждая в своих границах, как наш прежний путь (upstream `81f31263` дописывает недостающие нулями — свидетельства
  у нас нет; наш тест `BufferStoreFormatXChecksOnlyTransferredComponent` держит прежнее правило); упакованные битовые форматы пишут своё слово
  целиком, недостающие поля — 0 (как upstream; иначе слово не собрать). 4 кейса GPU-гейта `…Partial…` проверяют это правило.
- **T203.** `D = ({S0, S1} >> (8 · S2[1:0]))[31:0]` (upstream `f18679e0`, описание ISA RDNA2).
- **Старые кейсы, кодирующие прежний ответ**, следуют своей ручке: `VectorAlignByteUsesFiveBitByteOffset` (T203),
  `DsFloatMinMaxUsesSeparateCompareOperand` (T234), `ImageSampleA16OffsetKeepsTexelOffset32BitOnGpu` (T306; при `=1` — тексель `(3, 1)`).
  Полный набор `shader_recompiler_compute_tests` при `=1` не прогонялся (G1 — `shader_cfg_tests`); группы, которые могут кодировать прежнее
  поведение формата записи (`BufferFormatStoreVariants` и др.), — [U], на проверку M2c.
- **Флаги и состояние (правило отчёта).** Новых TLS, полей и счётчиков нет. `MThemeMask()::mask` — `static const`, ставится при первом вызове
  (конструктор кэша трансляции или первая трансляция), не снимается — значение процесса. Локальные `const` в пределах одного вызова:
  `m_t256`, `output_mode`, `sint16_raw` (`ExportVector`), `m_t306_offset`, `m_t306_packed` (`EmitImage`), `m_offset` (`IMAGE_SAMPLE`) — не
  переживают вызов, ранних выходов, где снятие требовалось бы, нет.
- **Строки журнала, читаемые нашими скриптами (п. 756(б)(4)):** ни одна прежняя строка не изменена и не удалена; добавлены `MWave1:` и
