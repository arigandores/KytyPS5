### (в) Причина ручного пути для 2-байтного формата [c текста и `git log`]

1. **Записана — в коммите, который ввёл правило:** `05565b59` (2026-09-05, «WIP: ASTRO BOT bring-up fixes»), комментарий у правила `NumBytesPerElement(format)
   == 2u`: «PS5 hardware compares against any format; Vulkan only allows comparison samplers on depth formats. 16-bit shadow maps rendered as R16 color
   targets (ASTRO BOT) are therefore compared in the shader», в сообщении коммита — «Vulkan has no depth-comparison support for R16_UNORM». То есть причина —
   **цветовой вид `R16_UNORM`**, который рендер тогда давал 2-байтной карте теней.
2. **Довода против нативного `D16` (VUID, артефакт) в записи нет.** Вид `D16_UNORM` образу сравнения `k16UNorm` даёт апстримный `9641b519` («render: fix
   tiled depth comparison textures», 2026-09-05; не предок `05565b59`) вместе с GPU-тестом `ComparisonDepthTexture`, который ждёт нативный `Dref` на `D16`;
   он пришёл слиянием с. 22–24. `HANDOFF.md` §2.30 (с. 24, `e6d8e0d`) называет оставленный ручной путь `R16` следствием переноса цикла без новой причины
   («теперь R16-теневые карты (2-байтный формат) остаются ручными, D32 — нативные»); с. 39 расширила ручной путь на все цветовые форматы ради VUID-06479 и
   отметила отказ `ComparisonDepthTexture` «ожидание native Dref для D16» как старый (`HANDOFF.md` §2.45). В снимках F14c у всех ручных мест `k16UNorm` — вид
   `D16_UNORM`, `aspect = DEPTH` [c]: условие записанной причины (цветовой вид) в наблюдённых кадрах не выполняется.
3. **Хост-сэмплер нативного места.** `975927c8:src/graphics/host_gpu/renderer/pipeline/descriptors.cpp:3383` (якорь «if
   (!program.info.samplers[index].depth_compare) {»; +1 — «descriptor.fields[0] &= ~(0x7u << 12u);») снимает функцию только у сэмплера без
   сравнения; `975927c8:src/graphics/host_gpu/renderer/cache/samplerCache.cpp:160` (якорь «sampler_info.compareEnable           =
   (r.DepthCompareFunc() != 0 ? VK_TRUE : VK_FALSE);»; +1 — «sampler_info.compareOp               = static_cast<vk::CompareOp>(r.DepthCompareFunc());»)
   ставит `compareEnable` и `compareOp` из функции S#; фильтр — гостя (`samplerCache.cpp:147`). Правки хоста не нужно [c кода]. Старые края, не новые для
   `=1`: функция S# 0 (`Never`) даёт `compareEnable = 0` при `Dref`, `ForceUnormCoords` — тоже (`samplerCache.cpp:176`); у `k32Float` так же сейчас.
