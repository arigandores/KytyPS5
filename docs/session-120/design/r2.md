# Session 120 — design R2: the stage image-block repeat census (knob `r2cen`)

Read-only code study (no build, no run, no source edited). Tree `C:/kyty/KytyPS5` at `996d565`; every file:line below is
that tree. Tags: **[M]** measured (run named), **[I]** inferred, **[U]** unknown. Reference designs:

counter selection, compare the full result with the memo).

## 0. Summary, and the plain statement the task asks for

* **What is counted.** Per `PrepareBindings` call (one shader stage of one draw or dispatch), whether the stage's IMAGE block
  repeats the previous call of the same stage TYPE with the same program — the same T# words in every slot — and whether each
  slot of it would be *reproduced* by a reuse: the memo slot it came from is untouched since (its `version` is unchanged) and
  the image passes the memo's own liveness test. The time of the image loop (`bl_res`'s span, no extra timestamp when
  `bindlap=1`) is booked by class: clean (every slot reproduced), mixed, other. After the loop the fresh result is compared
  with the previous one: **`r2_bad`** counts reproduced slots whose freshly resolved image id or desc differs (must be 0).
* **Knob** `r2cen` (`KYTY_R2_CENSUS`, 0..2, default 0, MEASUREMENT ONLY): 1 census, 2 census + a sampled read-only replay of
  the removable work (an in-run price proxy). Changes no value, no decision and no side effect of the emulator at any value.
* **Ceiling** = clean-block resolve time (scaled to the unperturbed arm) − the kept work (liveness + memo-version load +
  `LodStats::Touch` + `ConfigureImageSource` + `tick_accessed_last` + `TouchImage` + DCC-adoption check + `BindImage`) −
  the witness compare paid on every stage − the T# store paid on every non-repeating stage. Bracket `C_lo ≤ C_pt ≤ C_up`, §6.
* **Plainly: yes, the side effects make the removable part small.** A memo-hit slot costs ≈ 52.1 ns [I, s119 on `spk118`];
  what a reuse must still run is ≈ 27.5 ns of it (BindImage 8.49 [M s87 `bal87a`] + the memo-hit tail 15.00 [M s88
  `wit88b`] + liveness/version ≈ 4 [I]) — **more than half**. The removable part is ≈ 21–25 ns a slot: decode, the two
  XXH3 hashes, the index, the memo-line `memcmp` and the ~584-byte `ImageDesc` copy of the emit. Even if **every** one of the
  ≈ 47 136 memo-hit slots of a frame sat in a clean repeating block, the point ceiling is ≈ 1.1 ms [I] (before the
  LodStats term); at a 50–75 % clean share it is **≈ 0.5–0.8 ms [I]**. R2 **alone is expected to close**; the census is still worth its
  place in this build because it is cheap to add, prices the population the s119 package arithmetic (R1 + R2 + R5) guessed
  at, and turns the s85 slot-level repeat share (84.9 %, [M] on an old binary) into a block-level [M].

### 1.2 The side effects, one by one (the task's list)

| side effect | can a reuse skip it? | why | what the census counts |
|---|---|---|---|
| `LodStats::Touch` (`lodStats.h:31-37`) | **no** | `count.fetch_add(1)` per binding per draw — the guest reads the bank (`IT_GET_LOD_STATS`); not idempotent | `r2_cl_lod` (slots paying it) |
| `ConfigureImageSource` | **no** | cross-draw non-idempotent: another binding of the same image (other draw, other LOD range) can move `source_first_level`/`source_size`; its `is_bound` test (`textureCache.cpp:1227`) makes it order-dependent. Cheap on the settled path (two early-outs, `:1245-1248`) | `r2_cl_bc` (slots past the first early-out: BC image and not both first levels 0) |
| `tick_accessed_last` | only if `AgeTick()` equals the previous block's | GC safety; the value only ever moves up; a store of the same tick is a no-op | `r2_cl_tick` (clean blocks with the same tick) |
| `TouchImage` | only if `m_gc_tick` and `GpuTimeProfiler::Frame()` equal the previous block's | then it only increments `texlru_n`/`texlru_rep` and returns (`texlru=1`) | `r2_cl_lru` |
| `AdoptPendingDccForTexture` | only if `MetaEpoch()` did not move since the previous block's end, nor during this loop | `m_meta_epoch` moves on every change of `m_surface_metas` (`textureCache.h:303-307`), which is all the adoption reads | `r2_cl_dcc` (slots that reach the lock), `r2_cl_meta` (blocks where it was a no-op) |
| `BindImage` (`is_bound` …) | **never** | s85/s87 | — (every slot; priced at 8.49 ns [M s87]) |
| DCC clears (`MaterializeDeferredDccClear`) | not in `PrepareBindings` | they run per slot in `CommitBindings`' transit loop (`descriptors.cpp:1841-1845` callers) on `desc`/image state R2 leaves identical; the only input R2 could starve is the adoption above, which is kept | — |

**The primary R2 design keeps all of them** (no new witness beyond the memo's own), so the kept price per non-null slot is
BindImage + tail + liveness/version ≈ 27.5 ns. The `r2_cl_tick/lru/meta` counters only say how much a *later* variant could
shave (≤ ~5 ns a slot [I]).

### 1.3 The mechanism the census prices (never built here)

Per stage TYPE, keep the previous call's `prepared.images` (held by `std::swap`, O(1)) plus its T# words and program. On a
call: **W1** same program (pointer + `shader_hash` + slot count); **W2** every slot's `DescriptorValue` equal (early exit).
Then per slot, **R**: the memo slot the element came from still has the element's `memo_version` (no store, no stale mark
since) and the image passes the memo-hit liveness test — if R, keep the element and run the kept list of 1.1; if not, run
the full `ResolveTextureWith` for that slot. By construction R ⇔ "the full path would take the memo hit and return exactly
this element": a memo slot's `image_id`, `desc`, key and `dwords` change only together with `version++` (`:1533-1535`,
`:1698-1708`; `fast_view`/`fast_stamp` `:2600`, `:2615-2616` are not part of the result) and the memo is never reset
(`Memo()` creates it once, `:1723-1728`). `RebindImages`' `texfast` eligibility (`:2558-2566`) then sees the same
`(memo_index, memo_version)` as after a hit. This is why `r2_bad` is 0 **by construction** if that invariant holds — and why
it is worth counting: it is the invariant R2 (and `texfast`) rest on (§8).

```cpp
// Session 120, knob "r2cen" (MEASUREMENT ONLY, C:/kyty/s120/design/r2.md).  One entry per shader stage TYPE (the
// bindkey idiom above): what the previous ARMED PrepareBindings of that type resolved.  Read by nothing but R2Census.
constexpr uint32_t R2StageKeys = 16;
constexpr uint32_t R2MaxImages = 64; // = SlotStatImages

// The ImageDesc fields a reuse hands on.  Compared FIELD-WISE, never memcmp: ImageDesc carries padding (:1397-1400).
struct R2DescKey {
	uint64_t                  data_address = 0;
	uint64_t                  data_size    = 0;
	vk::Extent3D              extent {};
	ImageSubresources         resources {};
	vk::Format                pixel_format = vk::Format::eUndefined;
	Prospero::BufferFormat    guest_format = Prospero::BufferFormat::kInvalid;
	Prospero::ImageType       image_type   = Prospero::ImageType::kColor2D;
	Prospero::TileMode        tile_mode    = Prospero::TileMode::kLinear;
	ImageMetadataKind         meta_kind    = ImageMetadataKind::None;
	uint64_t                  meta_address = 0;
	ImageViewInfo             view {};
	TextureCache::BindingType type = TextureCache::BindingType::Texture;
	uint32_t                  source_first_level = 0;
	uint64_t                  source_size        = 0;
};

R2DescKey R2Key(const TextureCache::ImageDesc& d) {
	return {d.info.data.address, d.info.data.size, d.info.extent, d.info.resources, d.info.pixel_format,
	        d.info.guest_format, d.info.type, d.info.tile_mode, d.info.metadata.kind,
	        d.info.metadata.range.address, d.view_info, d.type, d.source_first_level, d.source_size};
}

// Bit mask of the differing field groups (0 = equal): 1 data, 2 extent/resources, 4 formats/type/tile, 8 metadata,
// 16 view, 32 binding type/source.  The caller ORs 64 for a different image id.
uint32_t R2KeyDiff(const R2DescKey& a, const R2DescKey& b) {
	uint32_t m = 0;
	m |= (a.data_address != b.data_address || a.data_size != b.data_size) ? 1u : 0u;
	m |= (a.extent != b.extent || a.resources != b.resources) ? 2u : 0u;
	m |= (a.pixel_format != b.pixel_format || a.guest_format != b.guest_format || a.image_type != b.image_type ||
	      a.tile_mode != b.tile_mode) ? 4u : 0u;
	m |= (a.meta_kind != b.meta_kind || a.meta_address != b.meta_address) ? 8u : 0u;
	m |= !(a.view == b.view) ? 16u : 0u;
	m |= (a.type != b.type || a.source_first_level != b.source_first_level || a.source_size != b.source_size) ? 32u : 0u;
	return m;
}

struct R2Slot {
	ShaderRecompiler::IR::DescriptorValue value;          // the T# as the snapshot held it
	ImageId                               id;
	uint32_t                              memo_index   = UINT32_MAX;
	uint32_t                              memo_version = 0;
	R2DescKey                             key;
};

struct R2Entry {
	const void* program     = nullptr;
	uint64_t    shader_hash = 0;
	uint32_t    count       = 0;
	bool        valid       = false;
	uint64_t    age_tick    = 0; // AgeTick() at the end of the entry's call
	uint64_t    gc_tick     = 0; // TextureCache::m_gc_tick ...
	uint64_t    meta_end    = 0; // TextureCache::MetaEpoch() ...
	uint32_t    frame       = 0; // GpuTimeProfiler::Frame() ...
	std::array<R2Slot, R2MaxImages> slots;
};

struct R2Table {
	std::array<R2Entry, R2StageKeys> entries;
	uint32_t                    rng        = 0x9e3779b9u; // xorshift32: the 1-in-8 sample must not alias VS/PS order
	uint32_t                    last_frame = 0;           // Frame() of the last armed call
	uint64_t                    sink       = 0;           // keeps the replay's compares alive
```

### 3.8 `descriptors.cpp` — `RenderExecutor::R2Census`, new function between `:2349` and `:2351` (`FindBuffers`)

```cpp
// Session 120, knob "r2cen" (MEASUREMENT ONLY, C:/kyty/s120/design/r2.md).  Reads this call's fresh result
// (prepared.images: untouched until RebindImages), the snapshot, the memo and the texture cache; writes only its own
// table, FrameStats counters and at most 40 + 20 log lines.  NEVER calls TextureCache::GetImage (it touches the LRU),
// never takes m_lock, never writes an Image, the memo or LodStats.
void RenderExecutor::R2Census(const ShaderRecompiler::IR::CompiledShaderInfo& program,
                              const ShaderRecompiler::IR::ResourceSnapshot& snapshot,
                              const PreparedBindings& prepared, uint32_t mode, uint64_t meta0,
                              uint64_t res_ns) {
	namespace FS = Common::FrameStats;
	using C      = FS::Counter;
	auto& tc     = m_context.GetTextureCache();
	if (!t_r2) {
		t_r2 = std::make_unique<R2Table>();
		t_r2->scratch.reserve(R2MaxImages);
	}
	auto&          t     = *t_r2;
	const uint32_t frame = GpuTimeProfiler::Frame();
	if (frame - t.last_frame > 1u) { // first armed call after an unarmed stretch (an ABBA block): no stale previous
		for (auto& entry: t.entries) {
			entry.valid = false;
		}
	}
	t.last_frame = frame;
	t.rng ^= t.rng << 13u;
	t.rng ^= t.rng >> 17u;
	t.rng ^= t.rng << 5u;
	const bool     sampled = (t.rng & 7u) == 0u;
	auto&          e       = t.entries[static_cast<uint32_t>(program.stage) % R2StageKeys];
	const auto     n       = static_cast<uint32_t>(program.info.images.size());
	FS::Add(C::R2Stages, 1);
	if (n == 0u || n > R2MaxImages || prepared.images.size() != n) {
		FS::Add(n == 0u ? C::R2NoImage : C::R2Big, 1);
		FS::Add(C::R2OtherNs, res_ns);
		FS::Add(C::R2OtherSlots, n);
		e.valid = false;
		return;
	}

	// W1 + W2: exactly the compare a real R2 runs on every stage before its loop (early exit).  Priced on the sample.
	const uint64_t c0      = sampled ? FS::NowNs() : 0;
	const bool     same_pr = e.valid && e.program == &program && e.shader_hash == program.shader_hash &&
	                         e.count == n;
	bool rep = same_pr;
	for (uint32_t i = 0; rep && i < n; i++) {
		rep = snapshot.images[i] == e.slots[i].value;
	}
	if (sampled) {
		FS::Add(C::R2CheckNs, FS::NowNs() - c0);
		FS::Add(C::R2Checks, 1);
	}

	// Per slot: R, the reuse predicate, evaluated from the MEMO and the CACHE (not from the fresh result), then the fresh
	// result is compared with the previous one.  Evaluated after the loop: exact for clean stages (only memo hits ran, so
	// no image was created, freed or flagged), conservative for mixed ones (a later slot's miss can kill an earlier
	// slot's previous image and make R read false where the real R2 would have reused - design r2.md section 11).
	const auto* memo = m_memo.get();
	uint32_t    sv_n = 0, r_n = 0, r_null = 0, bad = 0, div = 0;
	std::array<ShaderTextureResource, R2MaxImages> decoded; // reused by the clean pass
	if (same_pr) {
		for (uint32_t i = 0; i < n; i++) {
			const auto& b = prepared.images[i];
			const auto& s = e.slots[i];
			if (!(snapshot.images[i] == s.value)) {
				continue;
			}
			sv_n++;
			decoded[i]          = DecodeNativeDescriptor<ShaderTextureResource>(snapshot.images[i]);
			const bool is_null  = decoded[i].IsNull();
			const auto* prev    = tc.m_slot_images.try_get(s.id);
			bool        r       = false;
			bool        live    = false;
			if (is_null) {
				r = prev != nullptr; // bindpack's null-memo hit test (:1393)
			} else {
				live = prev != nullptr && prev->registered && !prev->binding.needs_rebind && !prev->depth_id &&
				       prev->info.data.address == s.key.data_address && prev->info.data.size == s.key.data_size &&
				       prev->info.extent == s.key.extent; // the memo-hit liveness test (:1483-1485)
				r = live && memo != nullptr && s.memo_index < RenderExecutorMemo::TextureSlots &&
				    memo->textures[s.memo_index].version == s.memo_version;
			}
			if (!r && !live) {
				continue; // a real R2 would fall back to the full resolve for this slot
			}
			const uint32_t dm = (b.image_id != s.id ? 64u : 0u) | R2KeyDiff(R2Key(b.desc), s.key);
			if (r) {
				r_n++;
				r_null += is_null ? 1u : 0u;
				if (dm != 0) {
					bad++;
					R2Log("R2Mismatch", 40, program, i, n, is_null, s, b, dm); // static atomic line budget
				}
			} else if (dm != 0) {
				div++; // information: reuse PAST the memo's version would have diverged from the full path
				R2Log("R2Diverge", 20, program, i, n, is_null, s, b, dm);
			}
		}
		FS::Add(C::R2SameProgram, 1);
		FS::Add(C::R2SlotSame, sv_n);
		FS::Add(C::R2SlotHit, r_n);
	}
	if (bad != 0) {
		FS::Add(C::R2Bad, bad);
	}
	if (div != 0) {
		FS::Add(C::R2Diverge, div);
	}

	const bool clean = rep && r_n == n;
	if (clean) {
		FS::Add(C::R2Repeat, 1);
		FS::Add(C::R2Clean, 1);
		FS::Add(C::R2CleanNs, res_ns);
		FS::Add(C::R2CleanSlots, n - r_null);
		FS::Add(C::R2CleanNull, r_null);
		// The drivers of the KEPT side effects (section 1.2), on the images the fresh loop bound.
		const bool metalock = Common::Gates::Enabled(Common::Gates::Gate::MetaLock);
		uint32_t   lod = 0, dcc = 0, bc = 0;
		for (uint32_t i = 0; i < n; i++) {
			const auto& d = decoded[i];
			if (d.IsNull()) {
				continue;
			}
			if (!program.info.images[i].written && d.MipStatsCntEn()) {
				lod++;
			}
			const auto* img = tc.m_slot_images.try_get(prepared.images[i].image_id);
			if (img == nullptr) {
				continue;
			}
			if (!img->info.IsDepth() && d.MetaCompress() && d.MetaAddr() != 0) {
				const auto meta    = d.MetaAddr() << 8u;
				const bool settled = metalock && img->info.metadata.kind == ImageMetadataKind::Dcc &&
				                     img->info.metadata.range.address == meta;
				dcc += settled ? 0u : 1u;
			}
			if (img->info.IsBlock() &&
			    !(img->source_first_level == 0 && prepared.images[i].desc.source_first_level == 0)) {
				bc++;
			}
		}
		FS::Add(C::R2CleanLod, lod);
		FS::Add(C::R2CleanDcc, dcc);
		FS::Add(C::R2CleanBc, bc);
		if (m_context.AgeTick() == e.age_tick) {
			FS::Add(C::R2CleanTick, 1);
		}
		if (tc.m_gc_tick == e.gc_tick && frame == e.frame) {
			FS::Add(C::R2CleanLru, 1);
		}
		if (meta0 == e.meta_end && tc.MetaEpoch() == meta0) {
			FS::Add(C::R2CleanMeta, 1);
		}
		// r2cen = 2: the removable work of these slots replayed READ-ONLY into the census's scratch - decode, both
		// MemoHashBytes, the index, the memo line and its 32-byte memcmp, and the emit (a TextureBinding built from the
		// memo slot's desc).  Warm (the loop just touched every line): a PROXY, sign of its error unknown (section 6).
		if (mode == 2 && sampled && memo != nullptr &&
		    !Common::Gates::Enabled(Common::Gates::Gate::TexMemo2)) {
			t.scratch.clear();
			uint64_t       sink = 0;
			const uint64_t p0   = FS::NowNs();
			for (uint32_t i = 0; i < n; i++) {
				const auto& res = program.info.images[i];
				const auto  d   = DecodeNativeDescriptor<ShaderTextureResource>(snapshot.images[i]);
				if (d.IsNull()) {
					const auto& ns = memo->null_textures[NullTextureKey(
					    res, res.written ? TextureCache::BindingType::Storage : TextureCache::BindingType::Texture)];
					sink += ns.valid ? 1u : 0u;
					t.scratch.emplace_back(ns.image_id, ns.desc, UINT32_MAX, 0u);
					continue;
				}
				const uint64_t rk = MemoHashBytes(&res, reinterpret_cast<const uint8_t*>(&res.indirect_resources) -
				                                            reinterpret_cast<const uint8_t*>(&res));
				const uint64_t h   = MemoHashBytes(d.fields, sizeof(d.fields), rk);
				const auto     idx = static_cast<uint32_t>(h % RenderExecutorMemo::TextureSlots);
				const auto&    ms  = memo->textures[idx];
				sink += (ms.valid && ms.resource_key == rk &&
				         std::memcmp(ms.dwords.data(), d.fields, sizeof(d.fields)) == 0)
				            ? 1u
				            : 0u;
				t.scratch.emplace_back(ms.image_id, ms.desc, idx, ms.version);
			}
			const uint64_t p1 = FS::NowNs();
			t.sink += sink;
			FS::Add(C::R2ReplayNs, p1 - p0);
			FS::Add(C::R2ReplaySlots, n);
		}
	} else if (rep) {
		FS::Add(C::R2Repeat, 1);
		FS::Add(C::R2Mixed, 1);
		FS::Add(C::R2MixedNs, res_ns);
		FS::Add(C::R2MixedSlots, n);
		FS::Add(C::R2MixedEqual, r_n);
	} else {
		FS::Add(C::R2OtherNs, res_ns);
		FS::Add(C::R2OtherSlots, n);
	}

	// This call becomes the next call's "previous".  The T#-word copy is what a real R2 pays on a non-repeating stage.
	if (!rep) {
		const uint64_t s0 = sampled ? FS::NowNs() : 0;
		e.program         = &program;
		e.shader_hash     = program.shader_hash;
		e.count           = n;
		for (uint32_t i = 0; i < n; i++) {
			e.slots[i].value = snapshot.images[i];
		}
		if (sampled) {
			FS::Add(C::R2StoreNs, FS::NowNs() - s0);
			FS::Add(C::R2Stores, 1);
		}
	}
	if (!(clean && bad == 0)) { // a clean stage without a mismatch already holds exactly this result
		for (uint32_t i = 0; i < n; i++) {
			auto&       s  = e.slots[i];
			const auto& b  = prepared.images[i];
			s.id           = b.image_id;
			s.memo_index   = b.memo_index;
			s.memo_version = b.memo_version;
			s.key          = R2Key(b.desc);
		}
	}
	e.valid    = true;
	e.age_tick = m_context.AgeTick();
	e.gc_tick  = tc.m_gc_tick;
	e.meta_end = tc.MetaEpoch();
	e.frame    = frame;
}
```

## 6. Ceiling formula and bound

Per frame, means over the P blocks' frames 10–88 (ABBA, `KYTY_GPU_CLOCK_PIN=1`, BDA regime stated); `S = r2_cl_sl`,
`Z = r2_cl_nul`, `L = r2_cl_lod`, all in µs at the end:

* **Level scaling** (removes any uniform perturbation of the loop in P — R1's in-loop census, cache pollution):
  `f = bl_res_us(M) / bl_res_us(P)`; `T* = f × r2_cl_ns / 1000`.
* **Witness price** (paid on every stage with images): `CHK = (r2_chk_ns / r2_chk_n) × (r2_stg − r2_noimg − r2_big) / 1000`.
* **Store price** (paid on every non-repeating stage): `ST = (r2_st_ns / r2_st_n) × (r2_stg − r2_noimg − r2_big − r2_rep) / 1000`.
* Kept price per slot, pre-registered constants: `B = 8.49 ns` (BindImage, [M s87 `bal87a`]); `T = 15.00 ns` (memo-hit tail:
  Configure + tick + TouchImage + DCC check + one Add + way clock, [M s88 `wit88b`]); `V = 4.0 ns` (liveness + memo-version
  load, [I]); `LS = 3.0 ns` per LodStats slot (relaxed atomic RMW, [I]); `N0 = 2.0 ns` (null-image `try_get`, [I]);
  `P = 15.08 ns` (the s88 memo-hit proof, [M s88]).

```
C_up = T* − B·(S + Z)/1000                                   − CHK − ST     (only BindImage kept)
C_pt = T* − ((B + T + V)·S + (B + N0)·Z + LS·L)/1000        − CHK − ST     (the design of 1.3: all side effects kept)
C_lo = T* − ((B + T + P)·S + (B + N0)·Z + LS·L)/1000        − CHK − ST     (the whole proof kept: only the emit removed)
C_rp = (r2_rm_ns / r2_rm_sl) · (S + Z)/1000                  − CHK − ST     (r2cen=2: in-run replay proxy)
```

**Bound direction.** `T*` is the real in-loop time of the clean blocks. The kept work costs at least BindImage and at most
BindImage + the whole proof + the tail, so for this design **`C_lo ≤ true ceiling ≤ C_up`** within `bl_res`. `C_pt` is the
pre-registered point value. `C_rp` is a proxy of unknown sign: the replay is warm (under-states cache misses of the memo line
and desc copy ⇒ low) but isolated (does not overlap with kept work as it does in the loop ⇒ high). Outside `bl_res`, an
object-resident reuse would also skip `Reset()`'s `TextureBinding` destructors (`descriptors.h:123`, ≤ ~2 ns a slot ⇒
≤ S·2 ns ≈ 0.06–0.09 ms [I]) — uncounted, stated.

**Sanity (must hold, else the partition is broken and nothing is quoted):** clean price `p_c = 1000·T*/(S+Z)` within
25–90 ns; `K_rp = p_c − r2_rm_ns/r2_rm_sl ≥ B`; `C_lo ≤ C_pt ≤ C_up`.

**Rule (to be written into ROADMAP before code, with 2SE over P blocks):**
1. FAIL (R2 unsound as designed, and the memo/`texfast` invariant broken — stop and investigate) if `Σ r2_bad > 0` over the
   run or any `R2Mismatch:` line exists.
2. **CLOSED** if `C_up + 2SE < 1 000 µs` — closed independently of the kept-price constants.
3. **OPEN** (a prototype with its own verify gate) if `C_lo − 2SE ≥ 1 000 µs`.
4. Otherwise R2 opens only if `C_pt − 2SE ≥ 1 000` **and** `C_rp ≥ 1 000`; else R2 is closed as a track of its own and
   `C_pt` enters the image-resolve package sum with R1 (disjoint: R2 counts only memo-hit-equivalent slots, R1 only misses).
5. Information only, not in the rule: the per-slot variant `C_ext = C_pt + r2_mx_eq·(p_c − B − T − V)/1000` [I: a mixed
   stage's R slots priced at the clean average], and `r2_sl_hit / bl_res_n` against s85's `R_img_sh` 84.9 %.

**Expected [I]:** `r2_stg ≈ 9 400`; clean slots 50–75 % of `bl_res_n`; `p_c ≈ 50–55 ns`; `C_up ≈ 0.95–1.5 ms`,
`C_pt ≈ 0.5–0.8 ms`, `C_lo ≈ 0.25–0.45 ms` ⇒ most likely rule 4 → closed alone. Upper limit of `C_pt` at a 100 % clean
share ≈ 2.51 (T*) − 1.30 (kept, non-null) − 0.02 (kept, null) − 0.10 (CHK + ST) ≈ **1.1 ms**, before the LodStats term.
Arithmetic: T* at 100 % = 47 136 × 52.1 ns + 1 482 × ~40 ns; kept = 47 136 × 27.49 ns.

## 7. Own cost

## 8. The bad check

`r2_bad` += every slot with **R true** (the reuse predicate, evaluated from the memo slot's `version` and the image's
liveness — not from the fresh result) whose **fresh** result differs from the previous: image id (index + generation) or
any key field group of the desc (data range, extent/resources, formats/type/tile, metadata kind/address, the whole
`ImageViewInfo`, binding type, `source_first_level`/`source_size`), field-wise. Null slots: R = the previous null image is
still allocated (the `bindpack` hit test `:1393`); same comparison.

What it proves and what it cannot: it is **0 by construction if and only if** the memo invariant holds — slot content
changes only with `version++` (`:1533-1535`, `:1698-1708`), the memo is never reset (`:1723-1728`), and the index function
is stable between the two calls. A nonzero value therefore means the ground R2 (and `texfast`, `:2558-2566`) stands on is
broken: a stop, not a tuning. It is not an independent oracle of image correctness — nothing in a census can be; the full
path IS the oracle, and R is compared with it every time.

`r2_div` (information, not in the rule): slots where the memo slot moved (R false) yet the previous image is still live and
the fresh result differs — the cost of any "reuse past the memo" idea (the R1 ∩ R2 overlap): nonzero is expected when a
re-resolve recomputes `source_first_level`/`source_size` or `min_lod` differently from the frozen memo desc.

## 9. What must NOT change at gate 0 (and at 1/2)

* At `r2cen=0`: no census code runs except the knob load and three register operations outside the loop (the `r2_t0`
  test, `r2_res_ns = 0`, and the `r2_res_ns = bl_now − bl_t` subtraction at the head of `bl_smp` — the same instructions in
  both arms of any contrast); no allocation (`t_r2` stays null), no `MetaEpoch` read, no stamp, no `Enabled()` call
  added; the image loop `:2211-2267`, `ResolveTextureWith`, `BindImage`, `RebindImages`,
  `CommitBindings`, the texture cache, the memo and LodStats are byte-for-byte the current code.
* At any value: no emulator state is written — no Image field, no memo slot, no LRU (never `GetImage`), no `m_lock`, no
  LodStats bank, no `m_bound_images`; the census writes only `t_r2`, FrameStats counters and ≤ 60 log lines. No `EXIT` is
  reachable that the real path would not reach first (`NullTextureKey` on a resource the real null path already keyed).
* Existing counters keep their meaning: `bl_res_us`/`bl_res_n` get no new instruction inside their span when `bindlap=1`;
  `bl_smp_us` gets one subtraction+store at its head (≈ 0.3 ns a stage); the census lands only in `bl_prep`'s DERIVED
  remainder (and `mh_bind`). `texlru_n/texlru_rep` are untouched (TouchImage is never called by the census).
* No always-on code added anywhere else (no epoch in `textureCache.cpp`); nothing under `src/graphics/shader/**` (the
  translation-cache signature does not move); the `gates_base.txt` pins are unchanged.

## 10. Fixtures a scorer needs (each field on a synthetic `FrameTrace-x` line; suite ends with `ALL OK`)

1. **Arming**: P blocks `r2_stg == bl_prep_n` (± flip skew) and `r2_stg > 0`; M blocks every `r2_*` exactly 0; GateArm text
   parses `r2cen=2` in P and `r2cen=0`/absent in M, `bindlap=1`, `m4baton=0`, `texmemo2=0` in both (else NOT EVALUABLE).
2. **Time partition**: `|r2_cl_ns + r2_mx_ns + r2_ot_ns − 1000·bl_res_us| ≤ 1000 + skew` per frame (a mutant that forgets
   the ×1000 must FAIL; one that treats `r2_*_ns` as µs must FAIL).
3. **Slot partition**: `r2_cl_sl + r2_cl_nul + r2_mx_sl + r2_ot_sl == bl_res_n` (± skew).
4. **Class identities**: `r2_rep == r2_cl + r2_mx`; `r2_rep ≤ r2_prog ≤ r2_stg − r2_noimg − r2_big`; `r2_mx_eq ≤ r2_mx_sl`;
   `r2_sl_hit ≤ r2_sl_eq`; `r2_sl_hit ≥ r2_cl_sl + r2_cl_nul + r2_mx_eq`; `r2_cl_lod, r2_cl_dcc, r2_cl_bc ≤ r2_cl_sl`;
   `r2_cl_tick, r2_cl_lru, r2_cl_meta ≤ r2_cl`.
5. **Bad**: a line with `r2_bad=1` ⇒ verdict FAIL; an `R2Mismatch:` log line with all `r2_bad=0` ⇒ FAIL (the counter and the
   log must agree); `r2_div > 0` ⇒ no effect on the verdict.
6. **Sampling**: `r2_chk_n` within a 4σ binomial band of 1/8 of the stages with images; `r2_st_n` likewise of the storing
   stages; `r2_rm_sl` 0 when P carries `r2cen=1` (then `C_rp` NOT EVALUABLE and rule 4 falls back to `C_pt` alone — that
   fallback must be pre-registered, not chosen after).
7. **Scaling**: `f` from the same ABBA's M blocks; a fixture with `bl_res_us(P) = 1.10 × bl_res_us(M)` must scale `T*` down
   by exactly 1/1.10; a mutant using P's level unscaled must FAIL.
8. **Ceiling arithmetic**: synthetic means with known `C_up/C_pt/C_lo/C_rp`; boundary cases at 999.9 / 1 000.0 µs for each
   branch of the rule, including 2SE handling; the ordering check `C_lo ≤ C_pt ≤ C_up`.
9. **Sanity**: `p_c` outside 25–90 ns ⇒ NOT EVALUABLE; `K_rp < 8.49` ⇒ flagged (replay proxy rejected, rule 4 uses `C_pt`).
10. **Window**: frames 10–88 of every block; frames before the first `GateArm:` dropped; the first P frame after an M block
    carries `r2_prog == 0` for its first calls (table invalidated) — harmless, and outside the window anyway.
11. **Own cost line** (information): `Δbl_prep − Δbl_res − Δbl_smp − Δbl_sd` reported, not judged.
12. Mutants to carry: swap `r2_cl_*`/`r2_mx_*`; use `r2_sl_hit` as S; drop `CHK` or `ST`; scale CHK by `r2_chk_n` instead of
    stages; forget `Z`; read `bl_res_us` from P for `f`; ignore `r2_bad`.

## 11. Adversarial notes (risks)

1. **The side effects dominate** (§0): kept ≈ 27.5 of ≈ 52 ns; R2 alone reaches 1 ms only if ≈ every memo-hit slot of the
   frame sits in a clean repeating block. Block-level repeat must be below the slot-level 84.9 % [M s85].
2. **Shared P arm with R1**: R1's shadow-tag census, if it runs inside `ResolveTextureWith` on hits, inflates `bl_res` in P.
   `f` removes a uniform inflation; a non-uniform one (hits vs misses) is not removed. Integration constraint: R1's per-hit
   work should be deferred past the `bl_res` close (e.g. hashes collected in a thread-local list and processed in the
   derived remainder), or R1 must time its own in-loop cost so it can be subtracted from `T*`.
3. **Kept-price constants are cross-binary** (8.49 from s87, 15.00/15.08 from s88); `V`, `LS`, `N0` are [I]. The bracket
   `C_lo..C_up` is honest about it; the replay is the only in-run price and it is a proxy.
4. **Keying by stage TYPE** (`program.stage % 16`) is not the object keying of an in-place reuse (`m_graphics_bindings.vertex[i]`,
   `pixel`, `m_compute_bindings`): a tessellation draw between two VS draws breaks an object-resident chain but not the census
   chain. A swap-held per-type table (1.3) has exactly the census's semantics.
5. **Program identity** is pointer + `shader_hash` + slot count; a freed program whose address is reused by a same-hash program
   with a different image layout is not excluded (would surface as `r2_bad`/`R2Mismatch:` on the desc key, not silently).
6. **Post-loop evaluation of R** is exact for clean stages (only memo hits ran: no `FindImage`, no image created, freed or
   flagged) and conservative for mixed ones (a later slot's miss can kill an earlier slot's previous image: R reads false,
   the real R2 would have reused and agreed with the fresh hit).
7. **`r2_bad` is 0 by construction** under the memo invariant (§8): it guards the invariant, it does not replace the full
   path as the oracle.
8. **Thread-local table**: invalid with `m4baton ≠ 0` (a second thread runs the draw path); the scorer asserts `m4baton=0`.
9. **Own cost 0.6–1.3 ms/frame** in P lands outside `bl_res` but moves `dt`, `mh_bind` and `bl_prep` of P; only R2's counters
   and M-scaled `T*` are read from P.
10. **Pre-repair result**: the stored "previous" is `PrepareBindings`' result, before `RebindImages`' repair loop
    (`:2509-2521`); repaired slots store to the memo (version moves) so they read not-R next time — consistent, slightly
    conservative.
11. **Sampling** (1/8, xorshift): `CHK`, `ST`, `C_rp` carry sampling error; at ≈ 1 180 sampled stages a frame and ~80 frames a
    block it is far below the block-to-block spread.
