## 3. Правило версий `STATIC_KEY_VERSION` / `REPLAY_INPUT_VERSION`

- Где: `283a6ef9:src/graphics/host_gpu/renderer/pipeline/shaderReplay.h:41`–`44` (`FormatVersion`, `StaticKeyVersion`,

  семя `SpecId`; `ReplayInputVersion` — только строка совместимости и `LayoutLine`.

  `ComputeFromKey` — 14) и круг `BuildStageStaticKey(вход) == ключ` в перестройке — смена раскладки ключа даёт `rej_key`

## 5. Требуемые изменения

**RC1 (К1(4), К6) — `m_precache_stop` на настоящем пути закрытия не ставится; отмена перестройки — убийство процесса.**
Флаг ставит только `~PipelineCache` (`283a6ef9:src/graphics/host_gpu/renderer/pipeline/pipelineCache.cpp:4858`). Закрытие
окна на экране подготовки: `WindowPrepareShaders` → `false` → `std::quick_exit(0)` (`283a6ef9:src/emulator.cpp:188`–`189`);
обычный выход тоже `quick_exit` (`emulator.cpp:199`). `quick_exit` деструкторов не зовёт, а у подсистемы Agc есть только
`shutdown` (`283a6ef9:src/libs/agc.h:29`), `emergency_shutdown` нет — `WindowShutdown` → `~PipelineCache` не исполняются.
**Сценарий:** стенд `KYTY_S_REPLAY_TEST=stop` (или пользователь) закрывает окно на середине перестройки ⇒ в логе
`stand stop applied`, затем процесс снят `quick_exit` в любой точке цикла; ветвь `stopped` (`:7503`), строка
`rebuild … pipelines_bin=stopped` и строки `rebuild-src`/`rebuild-spec` не появляются никогда; комментарий
`shaderReplay.cpp:96`–`97` («the shutdown path stores m_precache_stop») и строка К1(4) README §1 неверны. Обрыв посреди
`ShaderTranslationCache::Save` (удаление старого файла, затем `MoveFileW`) теряет файл источника — следующий старт его
перетранслирует (безопасно [I]). **Изменить (одно из):** (а) кодом — на пути `WindowPrepareShaders() == false` поставить
`m_precache_stop` и дождаться потока precache до `quick_exit` (тогда К1(4) верен по букве, стенд меряет отмену); (б) пунктом
лида — К1(4) и К6 читаются как «обрыв убийством процесса», печать S17c называет признак обрыва (строка `stand stop applied`
без строки `rebuild records=`), комментарий и README исправляются. Без изменения S17c ждёт строку, которой не будет, и читает
К6 «не определено» или подбирает признак после данных.

**RC2 (К3, К4: знаменатель п. 531(в)) — precache регистрирует R-PIPE для каждого рецепта `pipelines.bin`, использованного
игрой или нет.** `ReplayCapturePipe` в `PrecachePipelines` (`pipelineCache.cpp:6860`–`6861`, `:6945`–`6946`) зовётся для
каждой записи файла рецептов до проверки `contains`; R-SPEC её стадий появляется только при попадании `Get`. **Сценарий:**
тег сбора `=2` на папке варианта, где уже лежит `pipelines.bin` текущей подписи из N рецептов (например, после прогрева FS8e
той же подписи `…:fixf19`), уровень использует M ≪ N ⇒ `pipes_waiting` at=stop ≈ N − M, знаменатель
`records + pipes_waiting` раздут, член К4 «≥ 0,90» ✗ при безупречной перестройке; заодно в `records` попадают пары стадий,
которых игра не рисовала (обе R-SPEC пойманы в других конвейерах). На холодной папке (нет `pipelines.bin`) precache не
работает, и счёт верен. **Изменить (одно из):** (а) печать S17c — тег сбора только на папке варианта без `pipelines.bin`
(с проверкой отсутствия файла до старта, строка `PipelinePrecache: no … yet` в логе — член годности); (б) кодом — R-PIPE из
precache помечать и печатать отдельно (`pipes_waiting_pre`), знаменатель К4 — без них (решение лида). Без изменения К4
читается на числе, зависящем от состояния папки, а не от кода.

**RC5 (К3, чтение `R_ADDR = 0`).** Сканер считает только не канонические значения в ролях, которые назначил сам писатель;
слова KEEP не проверяются (`283a6ef9:docs/track-s/s17a/r_addr.py:4`–`6`). `Canonical()` по построению пишет каноническую
форму роли, поэтому без стенда `addr` член `R_ADDR = 0` верен по построению (тавтология) и проверяет согласованность разметки
и целость файла, а не «адресов нет». Класс, который он не видит, — адресное слово, которое классификатор назвал KEEP
(чувствительное слово без найденного потока и без сдвига адреса); его охраняет только остаточная проверка писателя
(`shaderReplay.cpp:721`: точное равенство младшим 32 битам запрошенных адресов, `dw0` дескрипторов и `dw7` T#).
**Сценарий:** указатель p, по которому путь читает только `p + off` (off ≠ 0), а возмущение бит 8/0 меняет число чтений —
слово KEEP, в `addresses` его нет ⇒ записано как есть, `canon_residual` = 0, `R_ADDR` = 0. **Изменить:** лид читает член как
«разметка согласована», не «адресов нет»; справкой — счёт слов KEEP ≥ `0x10000` (сканер или строка `capture`), чтобы S17d
