## 1. Требуемые изменения

**RC1 (вывод (е)(2) по Б28 — сверх силы инструмента).** Положительный контроль покрывает половину сравнения: биты A `0x001`/`0x400`/`0x004` (сработали в `s3s127`); биты A `0x002` (K), `0x008` (F) и все биты B `0x010`–`0x200` (R, X, S, P, M, L) не срабатывали ни в одном прогоне за историю (F30a §2, §5 (1)) [c]. Б28 — это именно полнота НЕ-регистровых источников инвалидации; `=3` их не вооружает (таблица §0).
*Сценарий отказа:* после с. 127 появился источник, который двигает состояние цели мимо предикатов PB — например, материализация FCE Б42 делает `IsMetaCleared` истинным без сдвига `MetaEpoch` (тогда при `=0` захват ставит `depth_load_clear_enable` (`…:2194` «depth.depth_load_clear_enable = depth.depth_clear_enable || meta_clear;» (+1 «skc3_depth_mat                = meta_clear;»)), а пропуск `=1` его гасит (`…:3701` «state.depth_info.depth_load_clear_enable = false;» (+1 «}»)) — пропущенная очистка глубины). Сравнение `=2` это видит битом X — если компаратор B исправен. Если в нём дефект (поле `RenderState` вне `operator==`, снимок не там), серия даёт 0 `MISMATCH` на 6 из 8 сцен, и по (е)(2) Б28 пишется `НЕ ДЕФЕКТ` без единого свидетельства, что половина B вообще способна сказать «да».
*Изменить (решение F30c до серии, одно из двух):* (а) итерация кода — значение `KYTY_RT_SKIP=4` (= `3` и дополнительно не применять PB 3–4: эпоха метаданных и `state_serial`), контроль жив — ≥ 1 строка с битом из `0x3f2` на сцене; ревью кода до серии; либо (б) сузить вывод (е)(2): «Б14 и Б28 — `НЕ ДЕФЕКТ` по половине разрешения (биты A, источник — регистры и то, что двигает выходы разрешения); половина захвата и не-регистровые источники — «не определено» (у сравнения места B положительного контроля нет)», Б28 при (б) не закрывается. Без выбора — запись `НЕ ДЕФЕКТ` Б28 опирается на непроверенный инструмент.

**RC2 (член (С3) `rts_race` прячет сигнал).** Гонка гасит биты B без счёта `rts_bad` (`…:1562` «if (t_rts_race && (bits & kRtsBitsA) == 0) {» (+1 «FS::Add(FS::Counter::RtsRace, 1);»)); гонка — это первый медленный путь, вошедший со сдвинутым с момента быстрой записи `bind_stamp` (`…:1554` «t_rts_race = stamp_moved;» (+1 «}»)), т. е. цель изменили с другого потока — не-регистровый источник, которого `=1` в момент PB не видел. Во всех 4 прогонах с. 127 Σ `rts_race` = 0 (F30a §2) [c].
*Сценарий отказа:* на FS10 Б13 изменил порядок публикации эпохи BDA (FS9); пусть теперь отказ записи процессора двигает `bind_stamp` цели между PB и захватом. `=2` относит каждое такое расхождение к `rts_race`, (С3) делает тег «не засчитан», серия на остальных сценах печатает 0 `MISMATCH` и (е)(2) — `НЕ ДЕФЕКТ`. Новый источник исчез из вывода вместо того, чтобы его остановить.
*Изменить:* Σ `rts_race` > 0 у тега `=2` или `=3` — не исключение тега, а остановка серии и пункт лида (как (К′)), с печатью числа и кадров; считать по ПРОЦЕССУ, как вердикт (В) (сейчас (С3) — по окну, (В) — по процессу: гонка до строки входа гасит биты B незаметно).

**RC3 (положительный исход не должен требовать силы).** F30a §4.4: остановка — «первое (В) ≠ 0 на **засчитанной** сцене». Засчитанность требует (К), (С1)–(С3), (Д5), (Д6) — члены силы нуля.
*Сценарий отказа:* тег `=2` на `timestop_casino` дал Σ `rts_bad` = 3, но κ = 0,78 (доля пропусков `=1` на FS10 ниже средней линии курса) — тег «не засчитан», расхождение не читается, серия идёт дальше и пишет `НЕ ДЕФЕКТ` на 6 других сценах.
*Изменить:* любое Σ `rts_bad` > 0 или строка `RtSkipVerify:` у тега `=2` при выполненных (Д1)–(Д4), (Д7) — исход (е)(4) независимо от (К), (С), (Д5), (Д6). Члены силы относятся только к нулю.

**RC4 (новый источник после с. 127 на сценах серии не наступает).** Единственный новый пишущий путь рядом с защёлкой, который F30a нашёл, — FCE Б42 (§1.3, поведение [I]). Форма V Sky Garden в воду не входит: `b081117d:docs/ROADMAP.md:18780` «…на V харнесса Sky Garden (вход без ввода, Астро не входит в» (+1 «воду) не виден ⇒ `SCENE_OK` Sky Garden (п. 300) не снимается — форма V сцены не заходит в воду; …»).
*Сценарий отказа:* все 8 тегов `=2` — вход `-lvl` без ввода; материализаций FCE в окне 0; серия пишет 0 `MISMATCH` и `НЕ ДЕФЕКТ` Б28, хотя единственный кандидат на «источник, который защёлка не видит», не исполнялся ни разу.
*Изменить:* (1) член печати у каждого тега `=2`/`=3` — приращение `hit`/`applied`/`drawn` строк `FixB42:` (`dc5d4712:src/graphics/host_gpu/renderer/pipeline/descriptors.cpp:3747` «LOGF("FixB42: mode=%d hit=…») за окно и Σ `rts_lost` (`dc5d4712:src/graphics/presentation/videoOut.cpp:3185` «{"rts_lost", FS::Counter::RtsLost, false},»); (2) девятая сцена — Sky Garden в форме ввода воды F9g/FS3c (`fs3_u`, `KYTY_KEYS`) с контролем `=3` и тегом `=2`; (3) если `applied` = 0 во всех засчитанных тегах — вывод про источник Б42 «не определено» отдельной строкой.

**RC5 (текст: что доказывает ноль `=2`).** `=2` проверяет пошаговую эквивалентность на траектории `=0`; вывод о траектории `=1` верен, только если сравниваемое покрывает все побочные эффекты подменённых функций (F30a §1.5 — [I], таблицы нет). Проверено этим отзывом по коду FS10 [c]: пропуск A повторяет выходы, касание LRU и `BindRenderTarget`, `ps_active`; пропуск B — `MarkGpuModified`, `usage`, поля раскладки/доступа, экстенты, гашение `depth_load_clear_enable`; не повторённое — `Transit` (видно битом S через `state_serial`), `ClearMeta`/`TouchMeta` глубины (запись требует `!depth_clear_enable && !depth_load_clear_enable`; иначе бит X), имена Vulkan (отладка), переписи (гейты выключены), `ResolveColorTargets` (режим 3 исключён PA). Дыр в таблице не найдено [c на чтении, полнота I].
*Сценарий отказа без правки:* закрытие (е)(2) читается как «`rtskip=1` верен на сцене», а доказано «на траектории `=0` каждое место пропуска совпало по сравниваемым полям»; при переоткрытии спор о том, что было заявлено.
*Изменить:* в печать F30c и в строку реестра — форма вывода «пошаговая эквивалентность на траектории `=0` по полям битов (перечень); побочные эффекты вне перечня — довод с. 127 и чтение F30b [I]».

**RC6 (κ — исключение без решения).** (С2) берёт долю пропусков `=1` уровня из логов линии курса, смешивая режимы BDA (Sky Garden: 22 OLD / 52 NEW / 11 MIXED) и бинари. Совпадение популяций `=1`/`=2` доказано кодом (§0), κ лишь ловит неожиданный сдвиг.
*Сценарий отказа:* тег `=2` Sky Garden в OLD имеет долю PA∧PB ниже средней по смеси режимов на 25 % — κ = 0,75, обязательная S1 выбывает, серия по (К4) недействительна, хотя прогон годен.
*Изменить:* опору κ печатать по уровню И режиму (OLD/NEW по правилу §3); выход κ из [0,80; 1,25] — строка «справка, решение лида», не автоматическое исключение.

**RC7 (текст: тождества скорера — проверка разбора, не свидетельство).** `rts_chk` = `rts_pa` и `rts_chk_b` = `rts_pb` выполняются по построению: счётчики увеличиваются соседними строками (`…:3538` «FS::Add(C::RtsPa, 1);» (+1 «FS::Add(C::RtsChk, 1);»); `…:3708` «FS::Add(C::RtsPb, 1);» (+1 «FS::Add(C::RtsChkB, 1);»)).
*Сценарий отказа:* печать подаёт выполненные тождества как довод исправности самопроверки — тавтология, ловит только ошибку разбора строки.
*Изменить:* пометить в печати «тождество разбора».
