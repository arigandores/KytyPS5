# Сессия 63 — профиль потока с `recimg recup recpubn=16`, пиннинг потока записи (`recpin`) включён по умолчанию

База: `merge-upstream`, HEAD сессии 62 — `9b50340`. Итоговый коммит **9bfdcfd** (хэш дописан следующим коммитом). Push нет.

## 1. Главный результат

- **`recpin=1` (поток записи GuestGpu на CCD потока GuestGpu, вслед за `dapin`) включён по
  умолчанию.** Sky Garden, свип `sky63a` (25 фаз по 500 present, три повтора, полоса 4700–5100,
  базы 6,56–6,67 мкс/draw, спред ±0,9 % после первой прогревочной базы, ядра 7,0–8,1 — без
  троттлинга): **−2,7 / −2,3 / −3,6 % CPU на draw** (профильная фаза −3,2 %), FPS
  +1,3 / +1,1 / +1,5 %; полосы 4300–4700 и 5100–5500 согласны (−2…−3 %). Пустыня −6,6 %.
  В сессиях 57–58 гейт мерился в связке `rall` (`recbatch`+`recrelax`+`recpin`) и порога не держал;
  сам по себе и после `recpack` держит.
- **Профиль потока GuestGpu (три профиля по 18,6 тыс. семплов, §2):** `EndRecord` 4,2 % (из них
  4,0 % — одна инструкция `xchg` публикации головы кольца) → с `recimg recup recpubn=16` 0,4 %,
  но `Drain` 1,5 % (дренажи перед прямыми записями: `rec_direct_us` 150 → 600 мкс на кадр); → с
  `recpin` **1,1 % (xchg 0,9 %)** и без роста дренажей (`rec_direct_us` 150 → 83, `rec_ccd_x`
  32/41 → 0). Цена xchg была ценой межчиплетного владения линией, а не самой инструкции.
- **Общий механизм «любая прямая запись — запись кольца» закрыт потолком.** С `recpubn=16 recpin`
  остаток дренажей 382 мкс на кадр (§3), из них конвертируемые сайты ≈214 мкс (0,7 % потока);
  остальное — 20 прямых draw на кадр (mesh + primitive restart, legacy quad list) с их закрытиями
  прохода. Черновик патча (`C:/kyty/s63/patch_recgen.py`, гейт `recgen`, 8 сайтов через
  `RecordOp::Callable`) написан, проходит `PATCH_DRY=1`, **не применён**: потолок ниже порога
  замера. Каталог сайтов — `docs/local-session-63-direct-sites.md`.
- **`recimg`+`recup`+`recpubn=16` поверх `recpin`:** −3,7 / −3,9 / −2,8 % против `recpin` −2,7 /
  −2,3 / −3,6 % — разница 0,6 % ниже порога; с пиннингом публикация дешева, а редкая публикация
  возвращает цену в дренажи (`rec_direct_us` 83 → 385). Все три остаются 0.
- `rec_direct_us` и время в `FrameTrace-direct:` теперь считаются и в `KYTY_FRAME_TRACE=lite`
  (в сцене они были нулями); цена — два rdtsc на прямую запись.
- **Вход в Sky Garden — первый после свежей сборки, без зависания** (1 из 1; сессия 62 — 2 из 2).
- Базы `sky63a`: **6,56–6,67 мкс CPU на draw, 29,5–29,7 FPS, CPU потока 32,0–32,4 мс, GPU
  14,4–15,4 мс, ~4 840 draw; с `recpin` 6,37–6,44 мкс, 30,0 FPS.** 60 FPS нет.
