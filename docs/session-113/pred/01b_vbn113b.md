## 1. What is tested

Build `7d9fa0288099204f16974292a0d474afee80e58df43770612e11b8d5db5d6e5f` (`6eb7d14`). Knob `bdanarrow`: a buffer
registration always marks the BDA stamps of its own tracking regions stale; at 1 only a guest-map move invalidates all
stamps; at **2 (this run)** a registration still invalidates all (today's behaviour) and every region that mode 1 would
have skipped — write stamp unmoved, not marked by a registration, scanned since the last guest-map invalidation — is
counted (`bda_nwould`); if its freshly collected dirty ranges overlap a registered buffer the stamp is read again:
unchanged → a miss of mode 1 (`bda_nmiss`, the first 40 logged as `BdaNarrowMiss:` with region, range and buffer),
moved → a race (`bda_nrace`; mode 1's next pass walks that region). `bda_nxthr` counts registrations marked on a thread
other than the scanning one. Defaults otherwise (`daslot=1 daguard=1 cspfree=1`).

## 4. Rule

BAD = Σ`bda_nmiss` + Σ`bda_nxthr` over all rows (`bda_nrace` is never part of BAD). **GO** if admitted, OLD and BAD = 0 →
seal the ship ABBA `bdanarrow=0|1`. **NO_GO** if admitted, OLD and Σ`bda_nmiss` > 0 → mode 1 is closed as built (the
`BdaNarrowMiss:` lines name what it would have left unsynced). **INVESTIGATE** if admitted, OLD, Σ`bda_nmiss` = 0 and
Σ`bda_nxthr` > 0 → neither GO nor closing: an unknown off-thread registrar is found first. **NOT_EVALUABLE** if admitted
but NEW. **NOT_ADMITTED** otherwise.
