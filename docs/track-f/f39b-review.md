**Главный сценарий отказа задания («исправлено» по `MainTaskLate` без пользы для ввода и кадров).** Тег `f24_u1` F39a §2 не опирается на `MainTaskLate`: члены — доставка настоящего сообщения клавиатуры (`in_lat_max_us`), окно (`hung_ms`), стена сна переехала (`jp_update_max_us`); положительный контроль `f24_u0` различает правку (в отличие от `hold`, где главный поток спит сам), проба жива (`in_pre_lat_max_us`). **В окне блокировки** этот сценарий закрыт. **Вне окна** он открыт: правка ухудшает доставку ввода пульта и задач главного потока (RC1), а ни один тег это не меряет — `f24_n1` вводит сценарием `KYTY_KEYS` мимо главного потока (`730ed40a:src/graphics/presentation/window/inputScript.cpp:197`). Это и есть «исправлено без пользы»: окно в 8-секундной модели живо, а пульт в каждой обычной минуте игры идёт хуже.
