## 2. Ридер `f20c_read.py` (п. 462(г)–(д), п. 451(е))

- **Сцена** — первая строка `Level has started: underwater_aerial_garden`; кончается следующей непустой строкой `Level has started:` или
  `Event: quit` (кадры после них не считаются). **Первый кадр сцены** — первый `FrameTrace: n=` с `draws` ≥ 100 после строки уровня (его
  `dt` не считается). **Кадр idx** — номер кадра после первого кадра сцены с 1; время кадра — сумма `dt_us` кадров idx 1…idx−1.
- **Интервал кадра** — строки лога между предыдущей строкой `FrameTrace: n=` и его собственной. **Строки дампа трансляции** — строки IR
  (первый непробельный символ `%`) и строки листинга GCN (`<hex>: X_`, не с табуляции), как в атрибуции F20a (`ir` или `gcn`).
- **Окно Б2** — кадры сцены 723–828; читается, только если в сцене есть кадр 828. **Вход тёплый** — окно читается и в интервалах кадров
  723–828 0 строк дампа; холодный вход в N Б2 не входит (п. 462(б)(3)). **Кадр Б2** — кадр окна тёплого входа с `dt_us` ≥ 100 000, в
  интервале которого 0 строк `Vulkan pipeline cache: saved` и 0 строк `BvhLoopCapTrip:` (п. 462(б)(2)).
- **Удержание Б32** — сцена со временем ≥ 300 с (сумма `dt_us` после первого кадра сцены); в N входят все удержания, холодные тоже
  (п. 462(б)(3)). **Кадр удержания** — `dt_us` ≥ 100 000, начавшийся на времени сцены ≥ 10 с.
- **Атрибуция** (порядок п. 451(е) / F20a): `Vulkan pipeline cache: saved` → Б33 (только на бинарях до `adb0c82f`) → `BvhLoopCapTrip:` →
  Б1б → строки дампа → Б5 → только `PriorityStall:` → «только `PriorityStall:`» → «ничего». **Неатрибутированный** = «ничего» + «только
  `PriorityStall:`» (п. 462(б)(4)).
- Пороги — константы ридера: `B2_LO, B2_HI = 723, 828`, `SLOW_US = 100000`, `WIN_US = 10000000`, `HOLD_US = 300000000`,
  `K1S_US = 1000000`, `HOLD_S = 330`, `N_TARGET = 30`, `TAG_MAX = 30`, база F20a `warm 6, b2 0, holds 8, unattr 0`.

## 4. Свод серии и чтение (п. 462(д); кандидат для F20d, не вердикт)

- **Б2:** N = 6 (F20a) + тёплые входы допущенных тегов; k = число входов с ≥ 1 кадром Б2. N ≥ 30 и k = 0 ⇒ кандидат `НЕ ДЕФЕКТ`;
  k ≥ 1 ⇒ кандидат `дефект`, p = k/N, интервал 95 % Клоппера — Пирсона (двусторонний); N < 30 и k = 0 ⇒ «недостаток».
- **Б32, Sky Garden:** N = 8 (F20a) + удержания допущенных тегов; k = число удержаний с ≥ 1 неатрибутированным кадром; то же правило.
- **Сколько тегов:** теги идут, пока тёплых N Б2 < 30 и сделано тегов < 30 (`NEXT` свода); 24 — при 0 холодных окон.
- Строка свода — `f20c_read.py --series` (файл `series.txt` после каждого `post_f20c.sh`).
