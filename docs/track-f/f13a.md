## 4. Строки ридера `f13a_read.py` (без вердикта)

- **вход** — первая строка `GuestOut: Level has started: ending_boss_after_credit`; строки `FrameTrace` после неё — k = 1, 2, …
- **конец карточки** — первая строка k после входа с draws < 100, идущая после (не обязательно сразу) серии ≥ 90 подряд строк с draws ≥ 300;
  нет — `NOT_FOUND`. `t(card)` строки лога — сумма `dt_us` строк от конца карточки до строки (отрицательно — до конца карточки).
- **draws** — гистограмма после конца карточки (6 первых); у `f13_k` — окна «конец карточки … первое нажатие» и «после последнего нажатия».
- **строки сцены** — каждая `Level has started:` и `LevelDocument Loaded:` после входа с k и `t(card)`; счёт после конца карточки.
- **`f13_rd`** — строки `RenderDoc: level started at frame`, `auto capture at frame`, `captured guest flip`, `capture finished`; `t(card)` строки
  `auto capture`, draws трёх строк после неё; `rd_after_card_10s` = YES при `t(card)` ≥ 10,0, NO при < 10,0, `NOT_DETERMINED` без строки захвата
  или конца карточки; `rd_finished`. Вне ридера (строки `times.txt`): число новых `.rdc`, sha256, миниатюра, строк `rd_list`, сводка `RDSUM`.
- **`f13_k`** — строки `InputScript: press <клавиша> at <с> s (present <p>)`: на каждое нажатие — k, `t(card)`, медиана draws 600 строк до и
  после, набор draws до следующего нажатия, строки сцены до следующего нажатия, кадр видео (первая запись `.idx` с present ≥ p).
  `presses_J_ge3_L_ge3`: J ≥ 3 и L ≥ 3; `keys_after_card_10s`: у всех нажатий `t(card)` ≥ 10,0; `keys_pause_10s`: соседние нажатия одной
  клавиши через ≥ 10,0 с по времени `InputScript`. Видео: записей `.idx`, однокадровых глитчей (`one-frame glitches: N`), лист.
- **удержание** — с конца карточки до последней строки; `hold_after_card_120s` = YES при ≥ 120,0 с.
- **помехи и смерть** — строки `Unhandled exception:`, `--- Fatal Error ---`, `--- Error ---`, `GpuHangAbort:`, `ErrorDeviceLost`; кадры
  ≥ 1 с (`dt_us` ≥ 1 000 000) после входа; `AsyncPipelines: skipped draw`; события окна (`minimized`, `restored`, `resized`, `size changed`,
  `lost keyboard focus`) и `Recovering Vulkan swapchain` (тег с `minimized` или `Recovering` — помеха, вопрос лиду о повторе, п. 273(з)).
- **бинарь и кэши** — `installed_sha` = `540c035a…`; первая строка `manifest_cmp.txt`.
