# Sealed pre-registration 01 — session 111: observation of the contention left under the new defaults (`obs111`)

**Immutable once written.** Recorded in `docs/ROADMAP.md` §0.1 ("СЕССИЯ 111 — ЗАПИСИ ДО ДЕЙСТВИЙ" item 1, commit
`1f488f7`) before this text.

## 0. Why

`obs107` (session 107, before `cspfree`): GuestGpu's contended wall at `PipelineCache::m_mutex` ≈ 422 µs a flip over 321
contended acquisitions, the holder the walker in ~99 % (tag 1 `QueueDrawAhead` 57.7 %, tag 2 compute prefetch 40.9 %).
`cspfree=1` (shipped in session 110) removed tag 2's holds. This run measures what is left, and decides whether
`daslot` (the M1 queue off the lock) is worth measuring.

## 3. Admission

Seal (`DRAFT`/`SEAL`), `IDENTITY`, `INPUTS`, `BINARY`, `PREREG`, the pin, no schedule / checkpoints / recording, the
gate text has exactly one `plkstat=` token and it is `plkstat=1` and names no `cspfree=`/`cspmemo=`/`cspfam=` (the
defaults run), one ok attempt with no hold exit and ≥ 285 s, exactly one `GpuClockPin:` line in mode 1, no failure
marker in the log or stdout, ≥ 5 000 `FrameTrace-x` rows with every counter in the window n ≥ 2100, `plkstat` armed,
`cspfree` armed (Σ`cspfree_hit` > 0) with Σ`cspfree_bad` = 0.

## 4. Rule

Per flip over rows n ≥ 2100: the contended wall by holder tag. **If tag 1 (`QueueDrawAhead`) carries ≥ 100 µs a flip ⇒
BUILD_DASLOT** (then `vds111`, pred/02); **otherwise LOCK_DONE** (the lock is finished as a lever; `daslot` is not
measured). NOT_ADMITTED if any term fails.

## 5. Predictions

P1 tag-2 contended wall ≤ 20 µs a flip · P2 tag-1 share of the contended wall ≥ 0.85 · P3 total contended wall in [150,
320] µs a flip · P4 the walker's prefetch hold `pl_wp_hold_ns` ≤ 20 µs a flip · P5 BUILD_DASLOT.

## 6. Must not be claimed

Any frame-time effect; that the waits are unbiased (the instrument inflates them); 60 FPS.
