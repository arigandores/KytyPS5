## 4. Строки ридера (`f9g_read.py`, по тегу; вердикт «ИСПРАВЛЕНО» ридер не печатает)

- **Строка `FixB42:`** формы п. 353(г)(3): `FixB42: mode=<0|1> hit=<n> applied=<n> drawn=<n> rearm=<n> hit_all=<n> last_frame=<n> extent=<w>x<h>

  экстента (до первой — 0).
- **Форма:** все строки `mode` = ожидаемому (1 у V/W/SG/HB, 0 у C0), иначе `FORM ERROR`; `GamePatch:` — 0.

  кадр видео v = present − 1, `.idx`). Фазы (форма F9d): подход present < 3841; **«в воде с вращением»** [3841, 5851) (v [3840, 5850));
  шаги [5851, 5951); **«неподвижная камера сбоку»** ≥ 5951 (v ≥ 5950) до последнего present прогона.

  роста `applied`. Печатаются первая такая строка (номер, present, фаза) и число таких строк в неподвижной фазе — справка.
- **(г)(2) C0** (п. 351(г)(2), п. 353(д)(2)): строка `mode=0`, `extent=960x540`, `hit` ≥ 1, `applied=0`; плитки — по листу (§5).
