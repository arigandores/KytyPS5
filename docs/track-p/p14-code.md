## 5. Вопросы лиду и варианты исполнителя

1. **`foreign` копий на первой записи** — копии лежат в `.bss` и инициализируются игрой один раз из ячейки № 2 (`__cxa_guard`), их
   «образ» — 0 до инициализации или float 1/60 после. *Вариант исполнителя (в коде):* на первой записи копия годна при 0 или
   `3c888889`, далее — только при записанном в прошлый раз. Остаток: если игра инициализирует копию в другом потоке между чтением
   ячейки № 2 и своей записью ровно на смене k, следующая запись увидит одно `foreign` — [I], не наблюдалось.
2. **Поля строки:** печатаются и `d=`, и `kraw=` (равны), чтобы читалось при обоих прочтениях п. 284(в) «строка несёт `d`… поле `kraw`
   строки = d».
3. **v — первый открытый дескриптор видеовыхода.** Игра открывает один [I]; при нескольких — счётчик первого.
4. **До открытия видеовыхода** `g_vb` = 0, d = 0 — k = 1 с переносом до −3 и `pvar_over`; кадровая функция до открытия не идёт [I] —
   гейт п. 284(д) смотрит `pvar_over` только на удержании.
