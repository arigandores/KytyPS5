## Класс (решение лида `ROADMAP.md` п. 752(в), обязательно)
Каждая тема (коммит или группа коммитов одной правки) — ровно один класс:
- **А** — у нас нет, относится к корректности ASTRO BOT (картинка, крэш, зависание, вход/удержание уровня, данные). Кандидат на перенос.
  Требует довода, что ASTRO BOT этот путь исполняет (опкод в `ophist.tsv` > 0, функция HLE, которую игра зовёт, путь рендера, который
  игра проходит, строка реестра/лога) — иначе не А.
- **Б** — у нас сделано (своей правкой) и проверено — не брать. Основание — строка нашего кода `b3dc9c67:<путь>:<строка>`, или строка
  реестра трека F (`register.md` §N), или пункт ROADMAP.
- **В** — пересекается с нашим кодом иначе (мы решили ту же задачу по-другому, или правка ложится на наш переписанный код) —
  решение по данным пунктом лида M1c. Основание — наша строка, где наш вариант.
- **В′** — upstream сделал то же лучше: ТОЛЬКО если есть проверяемое у нас свидетельство (дефект нашего варианта воспроизведён тестом,
  стендом, логом). Без него — **Б**. Ожидается редко.
- **Г** — вне цели: лаунчер/GUI, бренд, README/доки, CI, сборки Linux/macOS, заметки; а также правки для других игр/платформ в путях,
  которые ASTRO BOT не исполняет, — ТОЛЬКО со свидетельством [c] (опкод 0 в `ophist.tsv`; функция HLE не импортируется/не вызывается;
  платформа не Windows); иначе пометь уверенность `U`.
- **Д** — только скорость (без изменения ответа) — справка; перенос только при измеренном у нас A/B.
Утверждения upstream о проверке («fixes X», «tested») — для нас [I].

## Основание (якорь)
Для класса Б/В (и где уместно для А/Г) — ссылка `b3dc9c67:<путь>:<строка>` + ТОЧНЫЙ текст этой строки (якорь, обрезанные пробелы по краям)
+ ТОЧНЫЙ текст следующей строки (контроль +1). Проверь командой `git -C C:/kyty/KytyPS5 show b3dc9c67:<путь> | sed -n '<N>,<N+1>p'`.
Для Г по опкоду — основание `ophist:<famop>=0` (и для VOPC/VOP1/VOP2 обе формы). Для строки реестра — `register:§<N>:<ID>`.

## Судьба наших правок (член п. 752(г)(3))
Если коммит трогает файл, где живёт наша ручка (`KYTY_FIX_*`, `KYTY_S_*`, `KYTY_PVAR*`, `KYTY_GAME_PATCH`; см. `overlap.tsv`/`knobs.md`),
напиши строку «что будет с нашей правкой»: какая ручка в файле (строка реестра), задевает ли upstream её место (по `overlap.tsv` и по
чтению диффа), и что произойдёт при переносе (место не пересекается / конфликт — сохранить нашу правку X / upstream делает то же
иначе — выбрать по данным / upstream удаляет код, на котором стоит наша правка). Иначе `-`.

## Запреты
- Каждая команда Bash начинается с `[ -e C:/kyty/SEALED_RUN.lock ] && exit 3;` — замок есть: ничего не запускать и не писать.
- Игру/эмулятор не запускать, ничего не собирать, `cmake` не запускать, в репозитории ничего не менять (никаких checkout/commit/stash/
  worktree), push нельзя. Писать можно ТОЛЬКО свой файл результата в `C:/kyty/m657/m1a/agents/`.
- Python: `export PYTHONIOENCODING=utf-8`; запись файлов — `open(..., 'w', encoding='utf-8', newline='\n')`. Не писать через heredoc
  строки с обратным слэшем-n.
- В тексте не называть личные данные и чужие приложения.

## Выход
Файл `C:/kyty/m657/m1a/agents/<корзина>.tsv`, UTF-8, разделитель TAB, первая строка — заголовок, далее РОВНО одна строка на каждый
коммит корзины (все до одного, порядок как в корзине):
`sha	theme	theme_title	class	essence	basis	anchor	anchor_plus1	knob_note	relevance	conf`
- `sha` — короткий sha как в корзине; `theme` — ключ темы `<код корзины>-<слаг>` (латиница, без пробелов), одинаковый у коммитов одной
  правки; `theme_title` — название темы по-русски; `class` — одна буква из А Б В В′ Г Д; `essence` — что делает коммит (по-русски, ≤ 200
  знаков); `basis`/`anchor`/`anchor_plus1` — см. выше (`-`, если нет); `knob_note` — судьба нашей правки или `-`; `relevance` — довод
  отношения к ASTRO BOT (счёт `ophist`, строка реестра, лог, путь) по-русски; `conf` — `c` (проверено кодом/данными), `I` (вывод), `U` (не
  известно). TAB и перевод строки внутри полей запрещены.
Итоговое сообщение: число строк, счёт по классам, список тем А/В/В′ с одной строкой довода, сомнения.
