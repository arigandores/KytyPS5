### 3.2 `KeptNow` ⇔ `kept_applied` [c]

`KeptNow` = `m_fix ∧ bucket_stale ∧ ¬exact_stale ∧ ¬fallback`. `Report` пишет `fix=kept_applied` ⇔ `m_fix ∧ ¬exact_stale ∧ ¬fallback ∧ m_applied`,
а вызывается только при `bucket_stale` (с пробой) и `KYTY_DIAG_F5`. В цикле слоёв `PrepareDccClear` (единственное место чтения `KeptNow`) `m_applied`
истинно всегда: цикл доходит до `ClearImage` только при бите маски вида, и тот же проход снимает бит, `Applied(clear_mask != mask0)`. При
`exact_stale` или `fallback` ответ — «устарела», заливка сброшена (`metadata = Dcc{}`, маска 0) и выход по `Mask` до цикла — значит внутри цикла
`KeptNow` ⇔ `m_fix ∧ bucket_stale` ⇔ (при `KYTY_DIAG_F5=1`) строка `kept_applied` того же вызова. Без `Arm()` (запись не `PendingDcc`) `m_fix` = false —
`KeptNow` = false, события нет. Без `KYTY_DIAG_F5` строки нет, а окраска есть — решение (б)(7).
