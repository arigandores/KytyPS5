## 5. Вопросы лиду (по каждому — вариант исполнителя; до ответа скорер считает по варианту)

1. **Где считается слово `e1k`.** Вариант исполнителя: отдельным скорером `scp31b.py` после цепочки (§3), `gop31.sh` и его печать не меняются (тогда
   `07_p31.md`, `test_gop31.py` 129 и DRY не переделываются). Иначе — строка `--all` в `gop31.sh` и новая печать харнесса.
2. **Строки с повтором n.** Буква «число таких строк» — считаются все строки с n окна, в том числе повторы. На четырёх окнах P28 повторов нет
   (строк = кадров: 310 / 313 / 369 / 813).
3. **(iii) при `FAIL` по доле смен.** По букве «при исходе тега, отличном от `NOT_DETERMINED`» — `FAIL` по доле смен знака при k̄ = n/a тоже читается
   `NOT_DETERMINED` (фикстура r8). Вариант исполнителя — так и считать (буква); ослабления нет: `FAIL` не становится `PASS`.
4. **k̄ по `dt_us` ≠ k записи.** [c] `pr_C` (k = 2 в каждой строке записи, бинарь `9235a7ac`) даёт k̄ = 2,4548 по `dt_us`: интервал показа длиннее 2
   вблэнков. Буква (в)(1) мерит показ, а СКО считается на видеокадр (кадр записи = показанный кадр), так что k̄ по `dt_us` — та длина кадра, от
   которой зависит СКО (довод RC3). Вариант исполнителя — по букве.
