## The rule (as implemented by `shp121.py`)

- Window positions 10–88 of every block, `draws > 3000`; pairs = blocks (2k, 2k+1) of the ABBA sequence, both complete;
  ≥ 30 pairs. **Δ = mean over pairs of (P block mean − M block mean) of `dt_us`; 2SE = 2·stdev(per-pair differences) /
  √pairs.** `cpu_gpu_us` and game speed per arm (16 667 / mean `dt_us`) reported.
- Admission (NOT_ADMITTED): build, pinned clock, environment, hold, one attempt, this pre-registration, gates text,
  the arm assertions, `Gate:`/`GateArm:` lines, markers, skipped draws in a window, stream completeness (last line
  exempt), pairs, idle; the arming proof (every complete P block fills and evicts); no 8-way leak into M window rows;
  no layout switch inside a window; no verify-mode counter or `*Injected:` line anywhere; `tm8_x2 = tm8_cenoff = 0`.
- Not evaluable: arming on the paired window rows — P − M `tex_hits` ≥ +300 and key misses ≤ −300 a frame (item 5),
  and `tex_hits` P − M ≤ the M arm's own key misses (the RC8 ceiling); identities with the RC1 tolerances; the two arms
  in different BDA regimes; fewer than two pairs.
- Correctness over ALL rows (`tm8_bad`, `tm8_vctl_bad`, `tm8_relive`, `tm8_rbbad`, mismatch lines) ⇒ NO_SHIP.
- **SHIP iff Δ + 2SE < 0 (strict) AND the sealed `vfy121` result is PASS; otherwise NO_SHIP with the measured Δ.**

## Prediction (not a verdict input)

Δ ≈ −350 µs a frame (range −250…−500; the audit of session 120: realizable 0.25–0.50 ms of the 658.8 µs census
ceiling), i.e. game speed about +1 %. Power of one run at 2SE ≈ 0.14–0.18 ms: ≈ 79–95 % at −250 µs, 38–54 % at −150 µs.
Disclosed before the seal: in the seal-01 run (four arms in turn, no ABBA, `texfastcheck=1` in each) mode 1 averaged
`dt_us` 33 677 against mode 0's 33 621 — not a speed measurement, and it does not bear on this rule.

## Consequences

- **SHIP:** the default of `texmemo8` moves to 1 in a new commit (ROADMAP item before it); the measured Δ is the number
  quoted, never the census ceiling.
- **NO_SHIP:** the R1 track closes with its measured Δ (the 8-way memo does not pay on Sky Garden at this build); the
  knob stays 0 as a measurement tool.
- **NOT_ADMITTED:** one repeat `shp121r`. **NOT_EVALUABLE:** recorded; a rerun only by a new recorded decision.
