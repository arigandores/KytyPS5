## 5. Помехи, повторы и остановка серии (`m3a3_rules.next_step`)

- Повтор помехи — `<тег>b<k+1>`, k ≤ 2 на тег; исполнитель назначает его сам (п. 793(г)(2)); лаунчер пускает только тег, который

- После `HOST_INTERFERENCE` — повтор только при `hostload: over05 0` в момент запуска (иначе exit 13, не попытка) и затем допуске
  `procload` внутри `go_m3a3.sh` (п. 793(г)(2): «не раньше выхода постороннего процесса и допуска `procload`»).

  после строки события, п. 764(в)); иначе exit 14.
- **Стоп серии и пункт лида:** третья помеха на одном теге (любого рода; вариант исполнителя — общий счёт k для помехи хоста и события

  `ErrorDeviceLost` / `device lost` (п. 760); `RETURN_FAILED`.
- **Допущенный тег с членом [NO] — стоп серии** (вариант исполнителя для (ii), буква — для (iii)): по (г)(3)(ii) любой допущенный тег с
