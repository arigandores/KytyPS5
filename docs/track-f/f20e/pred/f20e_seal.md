## 4. Свод серии и правило остановки (п. 543(е); кандидат для F20f, не вердикт)

- **Б2:** N = 28 (F20a 6 + F20c 22, п. 543(г)) + тёплые входы допущенных тегов F20e; k = число входов с ≥ 1 кадром Б2 (база k = 0).
  Строка свода — правило п. 462(д) ридера F20c: k ≥ 1 ⇒ «кандидат `дефект`», p и интервал 95 % Клоппера — Пирсона; N ≥ 30 и k = 0 ⇒
  «кандидат `НЕ ДЕФЕКТ`»; N < 30 и k = 0 ⇒ «недостаток».
- **Б32 Sky Garden — серия F20e отдельно** (база не прибавляется): N = удержания допущенных тегов F20e (холодные тоже); k = удержания с ≥ 1
  неатрибутированным кадром по букве; строка свода — «k of N holds» с интервалом 95 % К — П при k ≥ 1, при k = 0 — односторонняя верхняя
  граница 1 − 0,05^(1/N) (0 из 29 — 0,098, п. 543(ж)); вариант F20a — отдельной строкой.
- **Правило остановки (п. 543(е)):** теги идут, пока не выполнены оба: (i) N тёплых Б2 = 28 + тёплые теги F20e ≥ 30; (ii) удержание

  Строки свода `STOP (i) … (ii) …` и `NEXT` — `f20e_read.py --series` (файл `series.txt` после каждого `post_f20e.sh`). Помеха в счёт
