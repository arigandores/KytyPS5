**RC13 — оба ПК проверяют только ветвь `n` ключа [текст].** Сон ПК-B — до `OnFlip` (§1 п. 6), ПК-C — на GuestGpu до флипа; ветвь `n + 1`

**RC14 — список атрибуции (д)(1) расходится с F25a §4.1 [текст].** П. 596: «Б5 / Б33 / Б1б»; F25a §4.1: «Б5 / Б1б (сохранение кэша на S18 —
