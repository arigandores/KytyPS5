Hazards for a Generic conversion: (1) publish only where no handle is held; (2) EndRendering → EndRenderingPacket in
the same change; (3) Transit with an explicit handle must be split (GetBarriers + state on the resolving thread);
(4) spans are borrowed — copy by value; (5) no m_scheduler access inside the callable; (6) handle lifetime by
DeferOperation as for BufferUpload; (7) PushGeneric publishes immediately (not throttled by recpubn), one heap
allocation per call.

GpuMark: `GpuMarkSlow` commandScheduler.cpp:656-665 writes a timestamp through `m_command.Handle()` mid-buffer,
hence PacketsWanted()==false under KYTY_GPU_TIME; every packet path must drop its marks (tiler :356,:389,
image :316, renderDraw :1899/:990, renderCompute :797, descriptors :1147).
