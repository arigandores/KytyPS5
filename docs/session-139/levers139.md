### 3.2 В2 — спин потока записи (`recspin`) как помеха потоку GuestGpu (цель — `cpu_gpu`)

- **Источник — S11, §8.4.7.**
  - На Skylake задержка `PAUSE` увеличена до «as many as 140 cycles» (раньше ≈ 10).
  - `PAUSE` отдаёт соседнему логическому процессору того же ядра (SMT) конкурентно делимые ресурсы: слоты фронтенда и RS.
  - Совет руководства: если ожидание длится тысячи циклов и дольше, лучше уступить ОС (`WaitForSingleObject`), чем крутиться.
  - **Внутреннее, внешнего источника нет:** довод «спин съедает турбо-бюджет пакета у соседних ядер» — в S11 его нет; руководство
    говорит только об экономии энергии `PAUSE` против пустого цикла. В ревизии 2 этот довод не используется.
- **Наш код.**
  - `SpinFor` (`commandRecorder.cpp:924–952`) опрашивает голову кольца с `_mm_pause` до `recspin` мкс (`:50–54`, `gates.h:431`;
    умолчание 300 мкс — `gates.cpp:302`). Цикл — `:961–970`.
  - На данных `rec_spin_gpu_us` 28 892,3 при `rec_sleep_gpu` 2,2 за кадр [c]: поток записи крутится ≈ 83 % кадра. Окно 300 мкс —
    порядка 10⁶ циклов, то есть «тысячи циклов и дольше» по S11.
  - Поток привязывается к ядрам по `recpin`/`dapin` (`pipelineCache.cpp:1869–1874`).
- **(i) ✗ по форме.** Уровень 28 892,3 [c] — на потоке записи, а не на потоке, держащем кадр. Уровень цели на GuestGpu — весь
  `cpu_gpu` 33 866,8; доля помехи в нём [U]. S11 говорит о помехе только соседу по ядру (SMT); делят ли поток записи и GuestGpu ядро
  при `recpin`/`dapin` на опоре — [U].
- **(ii) ✓ условно.** Меньший спин не меняет записанных команд: он меняет только момент, когда поток записи берёт пакет. Результат
  тот же по построению. Есть цена: сон потока записи переносит на GuestGpu цену пробуждения через `notify` (`rec_wake` 16,1 за кадр
  сейчас).
- **(iii) ✗ — основания нет.** Эффект спина на частоту или SMT потока GuestGpu в программе не измерялся. Строка §3 «`recpin` двигает
  поток и НЕ двигает GPU» (с. 85) — о цене GPU, не CPU. Даже знак [U]: при `recspin` → 0 GuestGpu платит пробуждения на 10 918,7
  публикациях за кадр. Цифра S11 «1–2 % на сильно многопоточных приложениях» — о смене задержки `PAUSE` между поколениями, а не о
  нашем спине; как середину её не беру.
- **(vi)** Новое: CPU-эффект спина против §3 не проверялся.
- **(vii) ✓.** Ручка уже в коде, без правки; ABBA ручки дозы — одна сессия.
