### 3.2 Арифметика PS 237 (SPIR-V снимка, `spirv-cross --vulkan-semantics`; номера — id SPIR-V)

Ветка `cb[152] == 0` (SDR): цвет сцены × экспозиция (`5580.x` = 1) + шум → обратимый тонмаппинг `%731..%733 = c / (1 + luma(c))` →
**смешение с цветом блока `[0..2]` с весом `%743 = bitcast(dword 3 блока)`**: `%744 = fma(w, k·C − c, c)` (так же `%746`, `%748`). При `w = 1`
результат — `k·C` = 0 для `C = (0, 0, 0)`, дальше обратный тонмаппинг и кривая дают 0 ⇒ выход (0, 0, 0). Второй путь (оверлей 5702 и строка
16–31: `cb[144] · lerp(5702.x, cb[16], cb[28])`) при `cb[28] = 1` и `cb[16] = 0` даёт 0 и выход не меняет. Базовое смещение блока
(`shader_data[32] & 255`) снимок не показывает — что вес читается из байт 12–15, подтверждает контрфакт 3.3.
