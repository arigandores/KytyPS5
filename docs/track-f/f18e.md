## 8. Варианты исполнителя (рядом с буквой; вопрос лиду — в отчёте звена)

1. «Подач порта в секунду» — порт в букве не назван. Читается: каждый выходной порт с `dev ≠ 0` и ≥ 2 строками `AudioStat` в W1 (строки
   `AudioStat` пишутся только для портов с устройством; у порта вибрации их нет: его подача идёт в `PushHapticsPcm`, а `QueueSdlAudio` выходит до счётчика при `audio_device == 0`
   [c `10a4800b:src/libs/audio.cpp:652`, `:917`–`:922`]); член — у каждого такого
   порта; сумма по портам печатается рядом. «Конец лога» — последняя строка `AudioStat` порта.
2. Время первой строки Ф8 у `f8_s0` — по скобке `t_us` (строка Ф8 своего `t_us` не несёт; метка лога и `t_us` — разные часы: `t_us` стоит в
   заморозках часов гостя, F18c §6); граница «не позже» включительная. Метка строки Ф8 печатается справкой.
3. A = 0 (ни один выходной порт не открылся — форма Ф23 хоста) — провал допуска: строки Ф8 быть не может, член `f8_n0` не определён по букве.
4. «Живой `init_calls`» у `f8_n0` (рост ≈ 1 за 3 с) — порог 0,25 в секунду `t_us` между первой и последней строкой `AudioStat` (1 за 4 с; ожидаемо
   ≈ 0,33).
5. `T_fail` у `f8_n0` — метка перед первой строкой Ф8 (форма F18a §2.1); окно включительное с обеих сторон.
6. Удержание `f8_n*` — `--hold 840` после «сцена стабильна» (буква «≥ 840 с»); `f8_s*` — `--hold 330`.
