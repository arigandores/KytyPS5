## 5. Предложение критерия до кода под `KYTY_FIX_SVAL` (для F10b; решает лид)

- **Что меняется.** При `KYTY_FIX_SVAL=1` `ValidateShaderSpirv` вызывает `tools.Validate(spirv.data(), spirv.size(), options)`, где в
  `spvtools::ValidatorOptions` `SetUniformBufferStandardLayout(true)` ставится тогда и только тогда, когда устройство включило
  `uniformBufferStandardLayout` (`src/graphics/presentation/window/vulkanWindow.cpp:705`). Значение передаётся из места включения;
  `ConstBankEnabled()` не подставлять — он требует ещё и `robustBufferAccess2`.
- **Что не меняется.** Прочие опции. При `=0` путь байт в байт прежний. Умолчание 0. Флаг читается один раз, семантика `envFlag`
  (`0/false/off/no` = ВЫКЛ). Правка в `src/graphics/host_gpu/**`, а подпись трансляции считается по `src/graphics/shader/**` +
  `shaderTranslationCache.cpp`, `gpu_format.h`, `gpu_defs.h` (`CMakeLists.txt:155-156`, `src/generate_version.cmake:44-56`). Кэш
  трансляции не холодеет — ревью проверить.
- **Чем проверить (офлайн, без замка).**
  - Тот же `sval_f10a` на новом теле (`extract_body.py` по коммиту правки) с переключателем.
  - `=0` — 151 из 151 REJECT, как сейчас.
  - `=1` — 151 из 151 и 51 из 51 (строки C) ACCEPT; 23 PS (к4) и 111 CS — ACCEPT.
  - Отрицательный контроль: модуль, который SDK отвергает и с `--uniform-buffer-standard-layout`, при `=1` по-прежнему REJECT. Среди
    442 модулей D такие нужно отобрать заново прогоном SDK с опцией; иначе — синтетическое нарушение.
- **Чем проверить (под замком, Harness Engineer).** Холодная трансляция (пустой каталог кэша трансляции), Sky Garden,
