Формат вывода:

```
SpecDump: file-sig file=<имя> sig=<строка подписи файла>
SpecDump: other-sig file=<имя> sig=<хэш транслятора>          (только при KYTY_TEST_SPECDUMP_SIG и чужой подписи)
SpecDump: file=<имя> stage=<VS|PS|CS|MS> hash=0x<16 hex> perm=<i> spec=<s>
SpecDump: failed file=<имя> stage=<стадия имени>  /  SpecDump: skipped file=<имя>  /  SpecDump: stage-mismatch file=<имя> key_stage=<стадия ключа>
SpecDump: stage=<стадия имени> files= read= failed= perms=
SpecDump: sig_filter=<хэш|none>
SpecDump: skipped= other_sig= stage_mismatch= spec_strings= spec_strings_aliased=
SpecDump: files=<N> read=<N> failed=<N> perms=<N>                (последняя строка)
```

- `stage` — стадия сохранённого ключа; `perm=i` — с 1, как `perm=` строки `AvTrace: shader-spec` (там `permutations.size()` после добавления);
- `spec=<s>` — хвост строки `AvTrace: shader-spec` после `perm=<n>` байт в байт, с ведущими пробелами; пустой без ресурсов;
- `spec_strings_aliased` — сколько строк (стадия, текст) стоят за ≥ 2 разными полными специализациями: текст `AvTrace` не печатает
  поля образа `indirect_mapping_offset`, `indirect_search_iterations`, `cube`, `manual_depth_compare`, `depth_compare_op`, `fmask`.

## 4. Справка: `perms` против `PipelinePrecache: 1842 recipes, 3456 sources loaded`

`perms` VS+PS+CS(+MS) = 794 + 247 + 141 + 5 = **1 187** ≠ 3 456 — объяснение [c кода]: счётчик строки precache
(`f18022a5:src/graphics/host_gpu/renderer/pipeline/pipelineCache.cpp:6630`, `loaded_sources += (vs_loaded ? 1 : 0) + (ps_loaded ? 1 : 0)`
на каждый графический рецепт; `:6715` — `cs_loaded` на каждый вычислительный) считает загрузки по рецептам с повторами, а не различные
перестановки: 1 660 графических + 141 вычислительный рецепт (строка `s10/log_t2_1.txt:2466`) дают не больше 1 660 · 2 + 141 = 3 461; дамп считает
каждую перестановку каждого файла один раз. Равенство не ожидается.

Стадия Mesh: 5 файлов подписи `699c1e4b` с именем `cs_` несут ключ стадии Mesh (`ShaderTranslationCache::PathOf` называет `cs_` всё, что не VS и не PS;
геометрические шейдеры гостя транслируются в mesh-стадию хоста) — в дампе `stage=MS`, в итогах стадий — в строке CS (по имени).
