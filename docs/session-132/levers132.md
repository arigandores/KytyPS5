- **Цель и уровень.** Фиксированная часть вызова `Protect` внутри `bda`: 81,36 вызова × 1,48 мкс = **120,4 мкс/кадр [c-OLS]**

- **Снимаемость по коду.** `SynchronizeBuffersOfDirtyRanges` (`bufferCache.cpp:3028`) при `protbatch2=0` зовёт `SynchronizeBuffer`

  регион до первой копии прохода даёт тот же порядок «защита → копия» (довод уже записан над `SynchronizeBuffersOfDirtyRangesBatched`,
  `:2953–2961`). Цена страницы (205,8 нс) при слиянии не уходит — уходит только фиксированная часть вызова.

  регрессия цены на вызов и страницу показывает, почему было в шуме (слияние снимает ≤ 18 % цены вызова). Новизны механизма нет.

  на GPU. Сузить без анализа адресов нельзя; а грязные байты, пропущенные этим сканом, синхронизирует следующий скан (≈ 19 промахов
