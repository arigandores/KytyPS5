## 3. Admission

As pred/01 §3, with **`STALL_SYNC` corrected**: the entry's `CsStall` lines logged AFTER its first `FrameTrace-x` row

## 4. Rule (unchanged from pred/01)

Per entry D = Σ `us` of ALL its `CsStall` lines (startup included), M = the longest; D_A, D_B sums over each arm's four
entries, M_A, M_B the longest. **NO_POWER** if arm A has no `CsStall` line. **PASS** if D_B ≤ 1.25 · D_A + 20 000 µs
AND M_B ≤ M_A + 10 000 µs. **FAIL** otherwise (then `cspfree` is not shipped; ROADMAP first). On PASS: the ship ABBA
(its own seal) before any default change.
