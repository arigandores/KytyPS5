## 2. Чтение часов (п. 234(е)(3)) в скорере

Пара — `GuestOut: Play: X` → следующая `GuestOut: Finished: X` (X — `.anim`), повторный `Play` перезапускает пару (правило P1);
на удержании — после первого кадра сцены (`draws` ≥ 100 после строки входа) и до конца удержания (смена сцены или конец лога).
Кадры пары — строки `FrameTrace` строго между строками; стена — Σ их `dt_us`. Кандидат — имя с парами в A и B; D = медиана
кадров A / 60; разброс по букве max \|f − med\| / med ≤ 0,02 (вариант `rng` печатается); отношение B/A — медиана по парам B;
имя часов — разброс и окно [0,45; 0,55]; скорость B = Σ D / Σ стены пар B имён часов; минимум 3 имени и 10 пар; контроль A
≤ 0,03; [0,9; 1,1] — отдельной строкой. Исход: `NOT_EVALUABLE` (допуск) → `PATCH_INACTIVE` → `CLOCK_UNDETERMINED` →
`SPEED_OK` / `CEILING` / `SPEED_LOW`. Проекция A — правило P1 §4, прочтение A.

Допуск плеча: сборка, sha печати в json, `KYTY_POKE` плеча, `KYTY_KEYS` = строке `keys:` печати, `KYTY_GPU_CLOCK_PIN=1`, без
`KYTY_GPU_CHECKPOINTS`, без валидации, попытка `ok`, `hold_s` ≥ 330, `hold_exit` нет, строки `KYTY_POKE: 0x… <- …` равны
ожидаемым (A — 1, B — 4; база 0x900000000), вход и первый кадр сцены, удержание ≥ 300 с, нет смены сцены, нажатия = плану и
все внутри удержания.
