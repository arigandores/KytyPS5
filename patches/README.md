# Патчи игры (по выбору)

## `PPSA21564_pvar.txt` — ASTRO BOT: скорость игры при FPS ниже 60

ASTRO BOT шагает симуляцию на постоянные 1/60 с за показанный кадр, поэтому при 30–40 FPS эмулятора игра идёт
примерно вдвое медленнее. Файл включает переменный шаг: эмулятор на каждом кадре пишет игре фактическое время кадра
(k/60, k = 1…3 вблэнка), а две правки кода игры отвязывают от шага ограничитель кадра и инерцию Havok. FPS не меняется,
меняется игровое время на кадр. Доказательство и границы — `docs/ROADMAP.md` «СЕССИЯ 122» п. 333 и 342 (трек P).

**Что нужно:** эмулятор из `main` начиная с коммита `4414e235` и этот файл. Игра (eboot, data) в комплект не входит
и не нужна: в файле только sha256 `eboot.bin` и наши новые байты.

**Как включить** — переменная окружения в том окне (или `.cmd`), из которого запускается эмулятор:

```
set KYTY_GAME_PATCH=C:\путь\к\patches\PPSA21564_pvar.txt
kyty_emulator.exe ...
```

Глобально (`setx`) не ставить: тогда патч включится и у прогонов, которые должны идти без него. Выключить — не задавать
переменную; без неё эмулятор файл не ищет и работает как раньше.

**Как проверить, что патч применён** — строка в `_kyty.txt`:

```
GamePatch: applied sha=3b5100797fe83663 pokes=2 pvar=2 audio_sync=0
```

Другая версия игры (другой sha256 `eboot.bin`) получает `GamePatch: refused reason=sha` — ничего не применяется, игра
идёт как без патча. Сломать чужую версию игры файл не может.

**На этой машине** — `ps5 em/docs/play_patched.sh` (запуск Sky Garden с патчем под замком, кэши и сохранения
возвращаются после выхода; см. `ps5 em/README.md`).

**Не заявляется** (п. 342(з)): что переменный шаг не ломает физику (проверено только листами видео); что шаг один на все
системы игры; что выключенный темп звука безвреден; скорость по часам игры на уровнях, кроме Sky Garden; что скорость
держится при FPS ниже 20 (шаг ограничен 3/60); что меняется FPS. 60 FPS не обещаются.
