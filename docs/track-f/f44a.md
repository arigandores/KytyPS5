### 0.4 Решения исполнителя по форме кода (не константы правила; на ревью F44b)

1. **Подпись функции.** `FaultAreaParse ParseFaultArea(const uint64_t* area, bool clamp, const FaultAreaVisitor& visit, const FaultAreaPass& pass = {})`: три параметра п. 698(в)(1) — как в решении; четвёртый (номер прохода `n` и номер области `a`) — только для полей строки `FixF29: overflow`. Строка и её предел 32 (`total` — счётчик проходов с переполнением на процесс) живут **внутри** функции, поэтому стенд, зовущий функцию эмулятора, видит ту же строку и тот же предел, что игра (член (1) «строк `FixF29: overflow` = min(32, …)» и мутант m6 ловятся стендом, а не только ревью). Номер прохода `n` — член `FaultManager`, растёт в `ProcessFaultBuffer` только при `=1` (п. 698(в)(2)); у стенда `n` — порядковый номер повторения. `FaultAreaVisitor` — `std::function<void(uint32_t, uint64_t)>` (функция в `.cpp`, не шаблон: стенд линкуется к телу эмулятора).
2. **Путь `=0`.** Отложенная операция зовёт `ParseFaultArea(faults, FixF29Enabled(), visit, {pass, area})`; визитор делает ровно прежние `fault_ranges.Add` и `LOGF` в прежнем порядке; `RangeSet`, `ForEach`, `FindBuffer`, `EXIT_IF` — без изменений. Дифф — разделом отчёта (член (д)(2)).
3. **Член H между процессами.** Порядок записей области задаёт порядок атомарных `atomicAdd` разборщика — между двумя dispatch он не обязан совпадать [I]; поэтому H сравнивает отсортированные списки страниц (`=1` против `=0` и против ожидаемого набора); «побайтно» — у отсортированных списков (sha256 отсортированного списка — полем TSV). Справкой в том же процессе — поле `h_inproc`: `ParseFaultArea` с другим `clamp` на той же копии областей, первые min(`raw`, 1 023) страниц в порядке записи — равны (тот же вызов эмулятора, `clamp` не из ручки — только для этого поля; члены P0/P1 берут `clamp` из ручки процесса).
4. **Раскладки битов** — генератор splitmix64 от зерна `KYTY_TEST_F29STAND_SEED` (по умолчанию названо в комментарии звена до зачётных данных): «один бит на слово» — `B` различных слов из 2²¹ слов карты, в каждом один случайный бит; D1 — 35 различных слов по 32 бита; порядок плеч в повторении — перестановка тем же генератором. Метки соседей: `faults[0]` = `C_N`, `faults[i]` = `P_N + (n_area · 1 024 + i) · 16 КиБ`, `P_N` = 2³⁶ (кратно 16 КиБ, < 2⁴⁰; номер соседа в метке — чтобы класс и источник прочитанного слова различались).
